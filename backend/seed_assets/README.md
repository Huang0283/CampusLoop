# 校内商城展示商品

这份目录保存可随项目启动恢复的展示商品与对应图片。商品通过后端初始化写入 PostgreSQL，图片上传到 MinIO；前端继续调用真实商品接口，不使用页面 Mock 或兜底商品。

## 本次整理

- 保留原有 109 件展示商品，新增 175 件，合计 284 件展示商品。
- 新增：服饰 30 件、文具 55 件、数码 59 件、家具家电 29 件、生活用品 1 件、其他 1 件。
- 家具家电新增包括冰箱和空调；单独空调内机在名称、介绍里明确说明不包含室外机。
- 新增介绍约 130–229 字，保留可核对的型号、尺寸、配件、使用痕迹与缺陷，删除外地交易地址、儿童用途、商家配送、原平台售后及引流用语，交接地点统一为校内公共交接点。不同种类使用对应的交接说明，避免无关关键词影响检索。
- 不编造未采集到的参数、购买经历、保修或配件。故障相机、污渍、裂纹、门胶条需更换、生锈、部分笔芯不出墨等信息保留。
- 新增商品目前每件有 1 张已配对的来源图片，未把其他商品的图片拼进同一图集。原有商品保留原图集。
- 图文配对候选中有 37 条未采用：含随机盲盒、未指明配件占位价、定制服务，以及图文或价格范围无法确认的记录。缺图候选不导入。

`showcase.json` 是运行数据；`products/` 保存被引用的 JPEG。`import-provenance.json` 保留本次新增的来源链接、原始文字、导入 ID、图片 SHA-256 和未采用原因。原始采集包保留在本地 `output/`，不将浏览器页面、账号信息或素材 ZIP 放入运行目录。

这是课程演示素材，展示卖家由种子账号提供，不能当作真实在校卖家或已验证成交记录，也不能直接当作智能组效果评估的真实交易数据。来源链接与历史介绍用于追溯，具体参数没有经过实物验货。

## 初始化与维护

日常网站使用仓库根目录的 `scripts/start-local.ps1`。正常启动会执行 `python scripts/seed.py --check`，验证两遍导入行数一致。已有账号密码、角色、账号状态，以及商品售出/预订状态、浏览和收藏计数不被重置。

商品使用预留 ID 1501–2000；原图 ID 保留，新扩展商品使用 50000 开始的独立图片 ID 段，导入后对齐序列。图片丢失或损坏会在写库前报错，禁止替换成占位图。更新商品时保留已有 ID，并确认图文、金额范围和配件对应。

写入型测试使用独立数据库与 Redis DB14/15。2026-10-29 使用 `campusloop_showcase_audit`、独立媒体桶和 Redis DB15 验证空库迁移、两遍初始化、账号与业务状态保持及商品/交易回归；日常账号库不运行这些验收写入。

验证结果：后端全套 183 项测试通过，前后端静态检查、前端构建与 SDK 生成校验通过。日常接口可见 299 件商品（包括此前已有的其他账号商品），284 件展示商品的 435 张图片逐张通过 HTTP、JPEG 解码与 SHA-256 对照。桌面和 390px 手机视口检查了服饰、文具、家电列表、详情、刷新与游客操作跳转，没有横向溢出和页面异常。导入前后现有账号密码、角色和状态的摘要完全一致。
