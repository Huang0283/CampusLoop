## 状态说明

- `候选`：已形成可评审文档，尚未完成全员确认。
- `已评审`：指定评审人已留下结论，遗留问题有负责人和期限。
- `已冻结`：M1 批准为当前基线，后续变更必须登记。
- `已完成`：实现、测试、文档和证据同时满足验收条件。
