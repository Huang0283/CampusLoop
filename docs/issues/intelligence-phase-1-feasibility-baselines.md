# AI-P1 数据可行性与规则基线

## 阶段信息

- 周次：第 1-2 周；截止：第一次汇报前。
- 成员：M7、M8；组内负责人：M7；评估复核：M10。
- 集成分支：`phase1/intelligence`。
- 输入：M1 范围、M3/M4 展示需求、M5/M6 业务字段、M9 环境约束。
- 输出去向：AI-P2、FE-P2、BP-P2、MQ-P2。

## 阶段目标

逐项判断语义搜索、供需匹配、价格建议、信誉和风险辅助是否可做。每项能力必须有数据来源、简单基线、评估口径、解释字段、降级路径和 `go/conditional/no-go` 结论；本阶段不承诺模型效果。

## M7 任务：搜索与供需匹配

- [ ] 定义搜索输入/输出、结构化筛选、排序字段和使用场景。
- [ ] 设计标题/描述/类别/品牌关键词基线及其失败边界。
- [ ] 设计关键词 + 语义 + 结构化过滤的候选混合检索流程。
- [ ] 定义求购匹配硬约束：类别、预算、成色、地点、有效期、商品状态。
- [ ] 定义软因素：标题、描述、品牌型号、用途及可解释匹配原因。
- [ ] 设计规则匹配基线、触发条件、结果版本和重复通知去重。
- [ ] 设计标注样本结构、正/负/难负例、复核与争议处理。
- [ ] 定义 Precision@K、Recall@K、MRR 的输入、计算和适用范围。
- [ ] 定义模型/索引超时或不可用时回退关键词/规则的行为。

## M8 任务：价格、信誉与风险

- [ ] 定义价格字段，严格区分挂牌价、成交价和人工参考价。
- [ ] 登记数据来源、许可、字段、样本量、时间范围、缺失和可用状态。
- [ ] 设计类别、成色、使用时间、原价等规则价格区间基线。
- [ ] 定义区间、影响因素、免责声明和服务不可用结果。
- [ ] 仅把回归模型作为数据达标后的候选，定义 MAE/MAPE/区间覆盖率限制。
- [ ] 定义完成交易、评价、取消、争议、举报对信誉的口径及新用户中性起点。
- [ ] 定义异常价格、频繁取消等人工风险线索及解释。
- [ ] 明确风险仅供管理员审核，不自动封禁或认定欺诈。
- [ ] 设计申诉、人工修改和重新计算候选流程。

## 必交产物

- [ ] 数据资产表：来源、许可、字段、样本量、时间、质量、敏感性、Owner。
- [ ] 智能能力矩阵：问题、输入、输出、基线、候选改进、指标、解释、降级、依赖。
- [ ] 搜索/匹配规则基线和公平对比方案。
- [ ] 价格规则区间、信誉规则和风险人工边界。
- [ ] 标注规范、评估集计划、数据泄漏与偏差风险表。
- [ ] 每项能力的 `go/conditional/no-go` 结论及证据。

## 验收与关闭

- [ ] 每项能力都有明确业务输入、输出、用户和 Owner。
- [ ] 搜索、匹配、价格均有不依赖复杂模型的可执行基线。
- [ ] 指标口径和评估集构建方法可由 M10 独立复现。
- [ ] 相似度不称为成交概率；价格不称为自动定价；风险不称为欺诈判定。
- [ ] 智能不可用不阻塞发布、浏览、聊天和交易。
- [ ] 所有数据来源有许可状态；未知数据不得填写虚假规模或效果。
- [ ] M7/M8 互审，M9 确认环境可行，M1 确认范围，M10 确认评估可执行。
- [ ] 汇总 PR 合并，AI-P2 对每项结论给出接收或删除决定。

## 本阶段不做

- 不训练复杂模型，不把 Isolation Forest 纳入 MVP 承诺。
- 不抓取许可不明数据，不使用真实个人隐私做实验。
- 不生成、猜测或美化任何尚未运行的效果数字。
