# MQ-P3 MVP 里程碑验收

## 阶段信息

- 周次：第 5-6 周；截止：第三次汇报前。
- 成员：M1、M10；主责：M1；独立验收：M10。

## MVP 验收路径

### 场景：账号

- 前置：空测试库
- 关键检查：注册、登录、刷新/退出、资料、越权
- 通过证据：API/页面记录和测试结果

### 场景：商品

- 前置：卖家已登录
- 关键检查：多图发布、列表、详情、编辑/上下架
- 通过证据：数据库持久化和页面更新

### 场景：交易

- 前置：买卖双方
- 关键检查：聊天、报价、接受、订单、约定、双方完成
- 通过证据：状态事件顺序和 E2E 录像/日志

### 场景：评价治理

- 前置：订单完成/未完成各一笔
- 关键检查：完成后评价；未完成禁止；举报可追踪
- 通过证据：权限/状态测试和后台记录

### 场景：降级

- 前置：智能/WebSocket 等不可用
- 关键检查：关键词、HTTP 补拉或明确不可用提示
- 通过证据：降级测试记录

## 发布门禁

- [ ] P0/P1 缺陷为 0；P2 均有 Owner、影响、计划且不破坏演示主路径。
- [ ] 前端 lint/build、后端静态检查/测试、迁移检查和 E2E 均有最终结果。
- [ ] 测试账号/数据不含真实个人信息，能够重复创建或重置。
- [ ] API 文档、页面映射、状态机和当前代码一致。
- [ ] 第三次汇报从空闲状态按脚本完成，不依赖开发者手工修数据。

## 本阶段不做

- 不为赶进度跳过权限、事务、迁移、异常或独立复测。
- 不把语义模型、价格模型或高级风险功能作为 MVP 关闭前置。
