# MQ-P4 智能集成与功能冻结

## 阶段信息

- 周次：第 7-8 周；截止：第四次汇报及第 8 周功能冻结前。
- 成员：M1、M10；主责：M1；质量门禁：M10。
- 集成分支：`phase4/management-quality`。
- 任务分支：`task/m1-p4-freeze`、`task/m10-p4-integration-test`；PR 目标：`phase4/management-quality`。
- 证据目录：`docs/evidence/phase-4/management-quality/`。
- 输入门禁：MQ-P3 MVP 标签存在；P0/P1 为 0；智能基线和接入契约可用。
- 输出去向：四组 Phase 5、冻结清单、第四次汇报。

## 阶段完成结果

至少两个智能功能在真实业务流程中可用，并能展示固定测试集上的基线对比、结果解释和不可用降级。第 8 周结束冻结功能，此后只允许修复、优化、文档和交付工作。

## M1 任务

- [ ] 确认本阶段纳入的智能功能及每项 go/conditional/no-go 最终决定。
- [ ] 组织智能输出、后端事件/落库、前端展示和测试的顺序化联调计划。
- [ ] 维护需求追踪，区分 MVP 已完成、Core 本阶段、Stretch 排除。
- [ ] 审批接口/字段/指标变化并更新受影响 Issue 与回归范围。
- [ ] 主持第 8 周功能冻结评审，形成冻结、遗留和删除清单。
- [ ] 编写第四次汇报脚本，明确真实指标、限制、失败样例和降级演示。
- [ ] 创建冻结版本候选标签，指定 Phase 5 基线提交。

## M10 任务

- [ ] 独立复现至少两个智能能力的基线与候选指标。
- [ ] 验证同一数据、同一过滤、同一指标下的公平对比。
- [ ] 验证智能超时、不可用、坏结果和旧版本结果的降级。
- [ ] 回归 MVP 主路径、权限、状态机和隐私，确认智能集成未破坏交易。
- [ ] 检查解释字段不包含概率误导、自动定价或自动处罚表述。
- [ ] 执行管理后台、风险线索、审计和错误状态测试。
- [ ] 建立 Phase 5 发布候选回归集和未关闭缺陷列表。

## 顺序化验收

1. M7/M8 提交版本化服务、数据与评估结果。
2. M6/M5 提交触发、权限、结果落库和人工处理接口；M9 确认运行资源。
3. M3/M2 接入结果与管理展示，保留基线/降级/不可用状态。
4. M10 独立运行评估与集成测试；M1 最后判断是否进入冻结范围。

任一步未完成，下游只能标记阻塞或使用显式 Mock，不得宣布端到端完成。

## 冻结门禁

- [ ] 至少两个智能功能真实集成，且基础方案在智能关闭时仍可用。
- [ ] 指标来自已提交评估输出，记录数据/代码/参数/环境版本。
- [ ] P0/P1 为 0；允许进入 Phase 5 的 P2/P3 均有 Owner 和修复期限。
- [ ] 新增需求入口关闭；例外必须有范围变更、风险与回归计划。
- [ ] 冻结清单列出保留、移除、部分完成、已知限制和提交号。

## 交接与关闭

- [ ] FE/BP/AI-P4 已关闭，所有跨组确认有记录。
- [ ] 第四次汇报完成并留存演示/问题/修复记录。
- [ ] M10 签署评估与回归结论，M1 签署冻结范围。
- [ ] Phase 5 四组 Issue 从同一冻结提交开始，仅处理明确交付项。
