## 可执行验收

- [ ] 从原始允许数据运行脚本可生成同版本处理数据和清单。
- [ ] 评估程序可计算约定指标；空数据、坏 schema 和缺字段会明确失败。
- [ ] 基线与候选方案使用同一测试集、过滤条件和指标。
- [ ] 搜索/匹配/价格响应包含解释、版本和降级状态。
- [ ] 智能超时或异常时，后端能选择关键词/规则或“暂不可用”，不阻塞交易。
- [ ] 敏感字段不进入模型输入、日志或公开解释。
