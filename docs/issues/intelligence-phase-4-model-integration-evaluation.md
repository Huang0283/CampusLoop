# AI-P4 模型集成与真实评估

## 阶段信息

- 周次：第 7-8 周；截止：第四次汇报及功能冻结前。
- 成员：M7、M8；组内负责人：M7；独立指标复核：M10。
- 集成分支：`phase4/intelligence-models`。
- 任务分支：`task/m7-p4-semantic-matching`、`task/m8-p4-price-evaluation`；PR 目标：`phase4/intelligence-models`。
- 证据目录：`docs/evidence/phase-4/intelligence/`。
- 输入门禁：AI-P3 基线固定；BP-P3 业务事件可用；评估集冻结。
- 输出去向：FE/BP-P4 集成、MQ-P4 冻结、AI-P5 最终复现。

## 阶段完成结果

在数据条件允许时交付语义搜索/匹配和价格建议候选模型，并与 Phase 3 基线公平比较。只有真实优于基线且可解释、可降级的能力进入冻结版本；不达标时保留基线并如实报告。

## 提供方顺序

1. M7/M8 先在冻结评估集运行候选，提交逐样本结果、指标、失败类别和版本。
2. M10 独立复现关键指标，确认无测试泄漏和口径变化。
3. 通过评估的服务版本交给 M6/M9 部署、触发和落库。
4. M3/M2 展示后再做端到端/降级验收。未通过步骤 1-2 的模型不得进入页面正式路径。

## M7 任务

- [ ] 实现候选向量模型、向量生成/索引和混合排序。
- [ ] 实现求购语义匹配，同时保留硬约束优先。
- [ ] 固定模型、预处理、索引、权重和服务版本。
- [ ] 与关键词/规则基线在同一评估集比较 Precision@K、Recall@K、MRR。
- [ ] 分析用途表达、品牌型号、短文本、冷门类别等失败样例。
- [ ] 输出可理解匹配原因，禁止将相似度称为成交概率。
- [ ] 提供超时/不可用回退和索引未就绪状态。

## M8 任务

- [ ] 审核价格数据量/质量；不达阈值时正式决定保留规则基线。
- [ ] 条件满足时实现可解释回归候选、区间估计和特征版本。
- [ ] 与规则基线同口径比较 MAE、适用范围内 MAPE 和区间覆盖率。
- [ ] 分析类别稀疏、异常价、时间漂移和低价样本失败。
- [ ] 验证影响因素解释稳定且不泄露敏感/内部字段。
- [ ] 完善信誉规则；风险智能实验仅作为 Stretch，不自动接入处罚。
- [ ] 提供模型不可用/低置信/数据不足时规则区间降级。
