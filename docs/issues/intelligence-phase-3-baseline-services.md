# AI-P3 可接入基线服务

## 阶段信息

- 周次：第 5-6 周；截止：第三次汇报前。
- 成员：M7、M8；组内负责人：M7。
- 集成分支：`phase3/intelligence-baselines`。
- 任务分支：`task/m7-p3-search-matching-baseline`、`task/m8-p3-price-trust-baseline`；PR 目标：`phase3/intelligence-baselines`。
- 证据目录：`docs/evidence/phase-3/intelligence/`。
- 输入门禁：AI-P2 数据/评估/服务契约冻结；后端事件与运行环境可调用。
- 输出去向：FE/BP-P3 基线联调、AI-P4 模型公平对比。

## 阶段完成结果

交付可真实调用的关键词搜索、规则供需匹配、规则价格区间及信誉/风险规则库。每项服务有版本、测试、解释和降级结果，为 Phase 4 模型改进提供固定比较基线。

## M7 任务

- [ ] 实现关键词搜索基线，支持约定字段、筛选、排序和分页。
- [ ] 实现求购匹配硬约束和软因素规则评分。
- [ ] 输出逐项匹配原因、基线版本和非概率分数说明。
- [ ] 实现新商品/求购触发任务、幂等键、结果版本和通知去重。
- [ ] 实现超时、坏输入、无候选和服务不可用返回。
- [ ] 在固定评估集运行基线并保存逐查询结果和汇总指标。
- [ ] 与 M3/M6 完成真实调用和至少一个降级场景。

## M8 任务

- [ ] 实现类别/成色/使用时间/原价规则价格区间。
- [ ] 输出影响因素、数据不足状态、免责声明和规则版本。
- [ ] 实现信誉聚合规则、新用户中性结果和可解释构成。
- [ ] 实现人工风险线索规则，仅生成线索，不执行处罚。
- [ ] 处理取消、争议、无效评价和人工覆盖后的重新计算。
- [ ] 在固定数据上运行规则基线并保存覆盖率、错误/边界样例。
- [ ] 与 M3/M5/M6 完成结果展示、权限和事实口径联调。

## 工程要求

| AI3-02 | M7 | 实现求购硬约束过滤和软因素规则排序，输出逐项原因 | 匹配代码/测试、matching-baseline.md | 违反硬约束候选为零，原因与得分组成一致 |

| AI3-07 | M8 | 实现风险线索规则、解释和人工审核输出，不执行处罚 | 风险代码/测试、risk-rule-service.md | 仅生成线索；账号、商品、订单状态不被规则直接修改 |
| AI3-08 | M8 | 在固定数据运行价格/信誉/风险规则并记录覆盖和边界失败 | 原始结果、rule-baseline-report.md | 报告区分有标签指标与仅规则验证，不混用口径 |

| AI3-10 | M7/M8/M10 | 提供复现命令、依赖、数据版本、参数和基线签字 | verification.md、handoff.md | M10 独立得到同一结果并确认其为 Phase 4 固定基线 |

- [ ] 服务入口使用版本化 schema；输入校验失败返回结构化错误。
- [ ] 数据/规则/参数版本与代码提交一起进入结果元数据。
- [ ] 相同版本和输入得到确定性结果；随机过程固定种子。
- [ ] 运行日志不包含敏感文本或个人身份信息。
- [ ] 单元测试覆盖硬约束、边界价格、空数据、重复任务和降级。
- [ ] README 给出安装、运行、评估、接口样例和已知限制。

## 可执行验收

- [ ] 关键词搜索能被前端/后端实际调用，并返回契约字段。
- [ ] 匹配先排除违反硬约束候选，再输出可解释排序。
- [ ] 价格输出区间而非保证价格，缺数据时明确不可用/宽区间。
- [ ] 风险线索不会自动修改账号、订单或商品状态。
- [ ] 关闭智能服务后，基础交易继续运行并展示降级。
- [ ] M10 可用同一命令复现基线指标和至少三个失败样例。

## 交接与关闭

- [ ] M7/M8 互审算法、数据口径和测试。
- [ ] M3/M5/M6 确认展示、权限、事件和事实口径。
- [ ] M9 确认运行依赖与资源；M10 复现评估；M1 复核范围。
- [ ] 汇总 PR 合并；AI-P4 以本阶段固定结果作为比较基线。

## 本阶段不做

- 不因模型尚未完成而阻塞基线服务交付。
- 不把规则分数包装成模型概率，不虚构基线优于其他方案。
