# AI-P3 可接入基线服务

## 阶段信息

- 周次：第 5-6 周；截止：第三次汇报前。
- 成员：M7、M8；组内负责人：M7。
- 证据目录：`docs/evidence/phase-3/intelligence/`。
- 输入门禁：AI-P2 数据/评估/服务契约冻结；后端事件与运行环境可调用。
- 输出去向：FE/BP-P3 基线联调、AI-P4 模型公平对比。

## 小组目标

交付可真实调用的关键词搜索、规则供需匹配、规则价格区间及信誉/风险规则库。每项服务有版本、测试、解释和降级结果，为 Phase 4 模型改进提供固定比较基线。

---

## 分支与合并要求

- 项目阶段集成分支：`phase3/integration`，由 M1 从上一阶段已验收的 `main` 创建。
- 小组集成分支：`phase3/intelligence-baselines`。
- 分支负责人：M7；组内交叉评审：M8；范围复核：M1；可测试性复核：M10。
- M7 从最新 `phase3/integration` 创建并推送 `phase3/intelligence-baselines`，在本 Issue 中记录远程分支链接。
- 远程分支链接：https://github.com/Huang0283/CampusLoop/tree/phase3/intelligence-baselines
- M7 个人任务分支：`task/m7-p3-search-matching-baseline`。
- M8 个人任务分支：`task/m8-p3-price-trust-baseline`。
- 所有个人任务分支均从 `phase3/intelligence-baselines` 创建，通过 Pull Request 合并回 `phase3/intelligence-baselines`。
- 禁止直接向 `main` 或小组集成分支提交；共享分支禁止 force-push 和变基改写历史。
- 任务 PR 必须写明任务编号、交付物路径、验证命令、验证结果、遗留问题和评审人。
- 个人任务完成并交叉评审后，由 M7 从 `phase3/intelligence-baselines` 向 `phase3/integration` 提交小组汇总 Pull Request。

## M7：搜索与供需匹配负责人

- 个人任务分支：`task/m7-p3-search-matching-baseline`。

### 个人任务

- [ ] **AI3-01**：实现关键词索引/查询，支持字段权重、结构化筛选、排序和分页。
- [ ] **AI3-02**：实现求购硬约束过滤和软因素规则排序，输出逐项原因。
- [ ] **AI3-03**：实现任务幂等、结果版本和通知去重，与 M6 的事件接口联调。
- [ ] **AI3-04**：在固定评估集运行关键词/规则基线并保存逐查询结果。

### 个人交付物

- [ ] **AI3-01**：worker/service 代码/测试、docs/evidence/phase-3/intelligence/keyword-baseline.md。
- [ ] **AI3-02**：匹配代码/测试、matching-baseline.md。
- [ ] **AI3-03**：任务代码/测试、matching-task-integration.md。
- [ ] **AI3-04**：原始结果、search-baseline-report.md。

### M7 验收标准

- [ ] **AI3-01**：固定查询得到确定结果，空/坏查询按契约返回。
- [ ] **AI3-02**：违反硬约束候选为零，原因与得分组成一致。
- [ ] **AI3-03**：重复事件不生成重复有效结果或通知。
- [ ] **AI3-04**：指标可由统一脚本重算，至少记录三个失败类别。

### 个人任务

- [ ] **AI3-05**：实现规则价格区间、数据不足状态、因素解释和免责声明。

## 工程要求

- [ ] 服务入口使用版本化 schema；输入校验失败返回结构化错误。
- [ ] 数据/规则/参数版本与代码提交一起进入结果元数据。
- [ ] 相同版本和输入得到确定性结果；随机过程固定种子。
- [ ] 运行日志不包含敏感文本或个人身份信息。
- [ ] 单元测试覆盖硬约束、边界价格、空数据、重复任务和降级。
- [ ] README 给出安装、运行、评估、接口样例和已知限制。

## 小组验收标准

- [ ] 关键词搜索能被前端/后端实际调用，并返回契约字段。
- [ ] 匹配先排除违反硬约束候选，再输出可解释排序。
- [ ] 价格输出区间而非保证价格，缺数据时明确不可用/宽区间。
- [ ] 风险线索不会自动修改账号、订单或商品状态。
- [ ] 关闭智能服务后，基础交易继续运行并展示降级。
- [ ] M10 可用同一命令复现基线指标和至少三个失败样例。

## 本阶段不做

- 不因模型尚未完成而阻塞基线服务交付。
- 不把规则分数包装成模型概率，不虚构基线优于其他方案。
