# AI-P5 复现、说明与最终交付

## 阶段信息

- 周次：第 9-10 周；截止：第五次汇报和最终提交前。
- 成员：M7、M8；组内负责人：M7；独立复现：M10。
- 集成分支：`phase5/intelligence-release`。

## 阶段完成结果

任何第三方可从允许的数据或已提交的可复现样本运行预处理、基线、候选和评估，得到报告中可解释的一致结论。未进入最终版本的实验与已完成功能严格区分。

## 修复与复现顺序

1. M7/M8 固定数据、代码、参数、模型和结果版本，不再更换评估口径。
2. M9 在发布环境执行服务/任务；M6 验证业务触发/落库；M3 验证展示。
3. M10 从文档独立复现指标和降级；差异先由 Owner 查明再更新报告。
4. M1 只引用经 M10 复核的数字和结论进入汇报/提交材料。
