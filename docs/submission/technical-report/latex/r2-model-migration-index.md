## Critical reconciliation

- Migration 0003 makes `orders.offer_id` unique and adds partial unique `product_id` for status NOT IN CANCELLED/DISPUTED. A product can have multiple historical orders.
- Migration 0003 makes message client IDs non-null and unique per sender even though the ORM annotation is optional.

- Migration 0013 limits duplicate report protection to PENDING/PROCESSING; handled history does not prevent a later report.
- `Report.target_id` is a polymorphic identifier, not a declared foreign key.
