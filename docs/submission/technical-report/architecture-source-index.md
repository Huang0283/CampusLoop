## Claim boundaries

- Contract tests and deterministic fixtures establish interface and fallback behavior, not model accuracy.
- No learned price model is claimed as trained or accepted; the current output is a degraded rule recommendation or unavailable result.
- Risk clues are not a fraud verdict and do not execute enforcement.
- Search and wanted matching require an independently reviewed, representative relevance set before an improvement or go-live claim.
- Price-model evaluation requires authorized real completed-transaction data and the thresholds stated in `ai-methods-and-limitations.tex`.
