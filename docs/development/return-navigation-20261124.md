# 业务流程返回入口（2026-11-24）

问题：匹配结果进入通知页后没有返回键；部分页面固定返回列表首页，丢失筛选、分页与通知分类。

统一复用 `frontend/src/live/BackLink.tsx`：前往子页面时记录来源 URL 和来源页面的路由状态；返回时恢复两者并替换当前历史记录，避免反复按返回在相邻页面之间来回跳。只接受本站已知业务路径；外部链接、协议相对链接、反斜杠、控制字符和当前页自身均使用安全默认去处。不使用 `history.back()`，新标签直接打开也有明确出口。

覆盖：匹配结果/匹配通知、头部通知铃铛、管理员通知、商品详情/发布/编辑/价格建议、求购详情/发布/编辑、订单详情/见面/评价、举报记录/关联对象、账号处理记录/申诉、个人资料、我的发布/收藏、聊天会话。一级市场、求购广场、聊天列表、交易中心及后台主导航仍使用原菜单；弹窗沿用关闭操作，没有统一再加一套弹窗。

通知分类、举报分页和处理记录分页通过 URL 保留；链接来源及其父级状态随浏览器 history entry 保存，同标签刷新后可返回原来页面。匹配通知入口直接选中“匹配”分类，名称中文/英文跟随界面语言。返回控件沿用现有链接样式与左箭头，不重做页面布局。
