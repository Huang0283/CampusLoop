# 商品标价参考

价格建议页保留原来的双栏界面，增加商品关键词。原价和关键词至少填写一项；关键词至少两个字符。通过 `/price-advice` 的 `marketReference` 单独展示在售标价，不把标价加入成交样本数。

## 数据范围

- 查询当前数据库中近 90 天上架、同分类、同成色、标题包含关键词的在售商品。
- 排除自己的商品、零价格、已删除或治理下架商品，以及禁用账号的商品。
- 最多取最近 100 件。至少 3 件才给出离散四分位区间；少于 3 件仍可查看匹配商品，但不生成标价区间。
- 展示最多 5 件参考商品，可进入商品详情核对型号和成色。
- 没有足够标价时，填写过原价可使用原来的成色规则估算；服务不可用明确提示，不编造价格。

当前商城包含展示商品。这里反映卖家标价，没有验证外部市场行情，也不代表实际成交价。标题包含关键词不保证同款；新商品与改价在下一次计算时重新查询，无需重新训练模型。
