# 商品图片与名称修复验收（2026-11-04）

## 问题与修复

中文模式原先只要看到三个拉丁字母就请求英译中，导致包含 Cosplay、ATX660 等字样的中文商品名称和简介被错误重译。自由文本还经过系统提示词的反向模板匹配，商品文字可能被当成界面提示。

- 中文及中英混排的商品原文在中文模式直接显示，不送模型重译。英文模式的系统词只做完整字符串匹配，自由文本使用商品翻译服务。
- 翻译服务同步保护中文原文，修正英文模式下型号先被拆成字母和数字的问题。新增型号回归用例包含 ZETA-X9、ATX660、Pad5、PB100DZM、26V。
- 为检查时商城公开展示的 396 个商品名称补充校对英文译文，按完整原文存入现有词表，不按商品 ID 覆盖。名称修改或新发布后使用原有翻译流程，品牌、型号和卖家昵称保留原写法。商品长简介仍使用模型翻译，不代表每句译文已经人工校对。
- 精简 50 个包含推销、使用说明等内容的名称，品牌、型号、关键规格及明显瑕疵继续保留；原名称完整追加至简介，避免遗漏原发布信息。种子数据同步修正。
- 列表、详情图库、缩略图和交易商品摘要改为完整等比显示图片，移除列表照片悬停放大造成的裁切。详情图的图片容器固定在图库内部，避免竖图撑出边界。
- 修复系统开启“减少动画”时语言选项定位到屏幕外的问题。仅对语言菜单关闭动画，其他界面动画规则不变。

保留现有正式页面布局和真实 SDK。改图前已对照 `frontend/src/pages/` 原始页面；未恢复 Mock 商品、身份或商店。
