## 本轮只测两项

使用 `permission/run2`，确认 `connection.json` 中的 `softwareSha`、UI 和 API 都属于上述 SHA。保留原 CSV 行，新增复测行和脱敏证据。

| 用例 | 操作 | 通过条件 |
|---|---|---|
| C12 自然过期 | 使用合法签发的 access token，先请求受保护 API 确认有效；等待自然过期，再请求 `/users/me`、本人订单读取或资料修改 | 原请求返回 `401 AUTH_ACCESS_EXPIRED`；写操作未生效。有效浏览器会话可以按设计续期，但不能把续期后的成功重试记成原过期 Bearer 被接受 |
| C34 伪造令牌 | 登录测试用户，复制实际 API 请求的 Bearer，篡改 JWT 签名后重放至 `/users/me`；保留有效浏览器 Cookie 作为对照 | 原请求返回 `401 AUTH_UNAUTHORIZED`，不自动调用会话续期，不返回用户资料；资料修改等写操作不生效 |

浏览器地址栏停留在 `/transactions` 或 `/profile` 不能单独判失败/通过。检查 Network 中真正的受保护 API 响应；截图遮住完整 Token、Cookie、密码及个人资料，只保留请求路径、状态码、错误码和测试角色。
