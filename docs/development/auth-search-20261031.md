# 登录提示与商品搜索修复（2026-10-31）

用户要求：中文界面的登录/注册反馈使用中文，注册前明确邮箱和密码格式；搜索商品名称及简介，新商品自动参与搜索，避免搜电脑出现无关商品。保留现有极光登录页和市场布局。

## 原因与修改

- 登录页直接显示后台英文 message 和内部错误码。现在按错误码显示中文，覆盖凭据错误、账号禁用、重复邮箱、限流、网络故障和服务故障；切换登录/注册会清除旧反馈。
- 注册页在字段下提示当前演示邮箱后缀 `@example.com` / `@example.invalid`，密码为 8–128 个字符，并明确表单校验消息。没有修改账号、密码或认证规则。当前站点没有英文语言切换功能。
- 市场搜索原来默认按发布时间排序，描述中顺带提到“电脑”的新商品会排到真正的电脑前面。M7 基线还对中文二元词采用 OR 匹配，使“购买电脑”命中仅含“购买”的无关商品。
- 实时搜索增加独立的短语匹配层：统一大小写/全半角、去除开头常见购买意图、要求所有空格分隔的词或连续短语出现在名称或简介中；短查询已有名称命中时不再混入只在简介提及的商品。电脑查询会把台式机、笔记本、MacBook 等数字设备标题当作名称命中，并排除文具本、充电线等配件误匹配。没有修改冻结的 M7 基线和求购匹配规则。
- 有搜索词时默认使用关键词和“最相关”；显式的最新/价格排序仍然有效。返回前继续复核在售状态、卖家状态和商品版本，分页使用过滤后的结果。
- 搜索字段本来就来自每次请求读取的当前数据库。发布、修改和下架后不需要训练或重建索引。搜索框跟随 URL/浏览器后退更新；搜索范围说明替代内部版本哈希，避免手机页面被长串撑宽。
- 复验日常目录的“电脑”查询返回 1597 联想台式电脑、1518 轻薄笔记本、1519 MacBook Air；1626/1628/1629 数码相机、1798 手提箱、1661 数据线、1534 电脑椅和 1512 键盘不再混入。没有名称候选时，简介仍作为回退搜索字段。

现有日常库未复现精确“电脑”返回被子，但已确认排序及宽松分词问题；“购买电脑”的无关命中能复现。修复后的日常 API 中，“电脑”及“购买电脑”首项都是联想台式电脑，“电脑 台式”只返回该台式电脑；相机、箱包、数据线、电脑椅和键盘等仅因简介提及电脑的商品会被排除。这不是完整的语义理解或图片识别，也未引入 Transformer。
