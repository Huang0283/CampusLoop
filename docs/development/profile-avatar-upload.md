# 个人资料头像上传（2026-11-02）

2026-11-05 安全修订：头像已改用私有存储与登录鉴权读取，旧公开副本在 API 启动前迁移并撤销。当前规则、迁移行为及复测方法见 [私有媒体访问](private-media-access.md)。下方验证记录为 11 月 2 日历史记录，不代表本次修复已部署到日常服务。

在个人资料原有编辑表单中增加头像上传、预览、更换及恢复默认头像。保留现有左右布局；上传后点击“保存资料”生效，成功后更新全局会话资料和顶部头像。正在上传时禁止保存，上传或保存失败显示中文说明并保留其他资料草稿。

支持不超过5MiB的JPG/PNG。后端实际解码校验，并将头像按照片方向居中裁剪为512×512的JPEG，不保留图片元数据。独立 `avatar` 上传用途现在存放在私有图片桶，聊天与举报证据也使用私有存储。保存头像时校验上传用途和当前账号归属；允许清空为默认首字头像，已有系统头像引用保持兼容。OpenAPI及生成的SDK类型已同步，无数据库结构迁移。
