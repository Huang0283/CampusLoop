# 前后台中英文切换与本地预览

本轮处理学生端、游客端，并按用户后续要求扩展到管理员后台。开发分支为 `fix/frontend-bilingual-20261103`，基于 `main@655337d`。2026-11-04 用户要求将本轮网站代码、测试和开发说明合并到 `main` 并推送；具体提交和同步状态可通过 `git log` 与 `origin/main` 核对。本地生成的截图、压缩包、其他任务产物，以及仓库外的 Obsidian 和全局技能配置不包含在本次网站提交中。

## 使用方式与范围

- 网站：`http://127.0.0.1:5174`，真实日常 API：`http://127.0.0.1:8001`。
- 首页、登录注册和市场顶栏提供“简体中文 / English”选择器，默认中文，只提供两种语言。刷新后保留选择；另一个标签页修改语言时，当前页和已打开的弹窗一起更新。
- 首页六张动画卡片、市场、商品详情、发布编辑、求购及匹配、价格建议、聊天、交易订单、见面评价、通知、举报记录和个人资料都接入显示语言。Ant Design 的弹窗按钮、上传提示和默认校验同步切换。
- 品牌和型号按原拼写保护；用户昵称、邮箱、账号标识保留原样。编辑框保存原始内容，显示翻译不会改写商品、用户资料、聊天、举报或交易数据。
- 英文卡片采用换行和局部间距调整；保留已有布局、配色、动画和真实 SDK 会话。手机顶栏压缩控件间距，避免新增选择器挤坏品牌标识。
- 管理员后台右上角、主题按钮旁加入语言选择，沿用前台的同一份偏好。仪表盘、图例/图表提示、举报处理、商品治理、订单管理、用户管理、风险线索、操作日志、个人中心和详情/处理弹窗随语言切换；原有权限守卫保留。
- 后台 CSV 的系统表头、分类和状态使用当前语言；导出的商品原始标题和用户昵称不改写，便于与原始交易记录对照。

## 两类内容怎样切换

1. 系统文案保存在 `frontend/src/i18n/messages.json`，由 `language.ts`、`Localize.tsx` 在 React 渲染前转换。只处理展示属性，不改 value、initialValues、ID、URL、回调和请求体。`OriginalText` 保护昵称等原文。
2. 新发布的商品名称、简介等动态文本使用 `CatalogText`。先查系统词典，再调用本地翻译服务，不依赖固定商品快照。新增商品无需人工往前端字典添加整条商品。
3. 表单只重新校验已经报错的字段。切换语言保留用户输入，不提前验证尚未操作的所有字段。异步翻译按原文和目标语言区分，旧语言请求完成后不能覆盖新语言视图。

## 本地翻译服务

入口：`services/catalog_translation_server.py`，依赖：`services/catalog_translation_requirements.txt`。使用本机 Marian 中英翻译模型，商品常用词见 `services/catalog_translation_glossary.json`。词条保护成色、配件、损坏、不可开机等常用表述；品牌、型号、数字和金额绕过模型保持原样。

首次配置：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/start-translation.ps1 -Prepare
```

日常启动仍然使用：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/start-local.ps1 -NoBrowser
```

启动器会附带启动本地翻译服务；停止日常网站时也停止该服务。服务只监听 `127.0.0.1:18790`。Vite 把同源 `/display-translation/*` 转发给该服务，浏览器无需直接连接自己的回环地址。需要其他部署方式时，可通过 `VITE_CATALOG_TRANSLATION_URL` 指定等价翻译入口，或在网站服务器上配置同源反向代理；仅上传静态 dist 不会自动部署 Python 翻译进程。

模型下载和翻译缓存位于 `%LOCALAPPDATA%\CampusLoop\translation`，不进入 Git。Python 环境位于忽略目录 `.codex-tmp/i18n-venv`，运行记录在 `.codex-tmp/translation-runtime`。启动器核对服务源码与词表摘要，代码变化后更新已有的本项目进程。翻译缓存按源码摘要区分，避免沿用旧词表的结果。

模型仓库：`Helsinki-NLP/opus-mt-zh-en`、`Helsinki-NLP/opus-mt-en-zh`。准备阶段下载模型，正常推理使用本地文件，不把商品、聊天等显示内容发送到外部翻译网站。服务不写账号数据库或图片卷。

动态内容首次加载使用浅色占位，不再显示“正在翻译 / Translating…”。同一页面的并发重复请求共用一次请求；内存及服务端缓存命中后直接显示。浏览器不持久保存聊天和举报正文。少见品牌、复杂口语和长句仍可能翻译生硬，需要继续按真实商品校订。服务不可用时保留原文并提供对应语言的失败说明，不编造翻译或隐藏商品。

用户截图中的众星 XQS 电动车和首页山地车简介补充了完整原文对应的人工校订译文，保留品牌、60V、不含电池和牌照、磨损等事实。词表按完整原文匹配，不按商品编号固定结果；编辑原文后会重新翻译。完整原文优先匹配，避免把已校订长句再次拆散。其他新增内容仍使用本地模型，不能将这两条校订结果视为所有新商品翻译质量的保证。
