# 商品语言往返与默认排序修复（2026-11-24）

## 原因与改动

- 原商品数据没有损坏。中文模式把含 Cosplay 的中文标题整体送入英译中模型，已有中文被重译，出现“剧本”等错误。现在英译中只处理英文片段，已有中文和中文标点始终保留；Cosplay / PVC 作为商品术语保留。品牌、型号、审计前缀及真实英文说明仍使用既有保护和翻译机制。
- 新增公开商品列表 `sort=recommended`：在数据库分页之前，将 `other` 分类排在常见分类之后，同组按发布时间、ID 倒序。商城无关键词浏览默认选择“推荐”。保留原“最新发布”、价格排序及搜索相关性语义，不删除、不隐藏任何商品，不按商品 ID 特判。
- 同步 OpenAPI、SDK 类型及 T1 响应契约源文件哈希；响应结构没有变化。

## 验证

- 翻译/缓存单测 8 项通过，含四个真实 Cosplay 标题双向校对、现有中文和品牌重叠保护、新英文说明不会把中文送进模型。
- 实际本机翻译模型：日常商城四个 Cosplay 商品的标题与简介共 8 段，通过中文 → 英文 → 中文原文显示检查；没有改数据库内容。
- 独立审计数据库、Redis DB14：商品排序、关键词搜索及校园目录集成回归 45 项通过，含跨页无遗漏、`other`/`OTHER` 后排、明确排序与分类筛选不受影响。没有向日常账号库创建测试商品。
- Playwright 双语及商品展示 15 项通过，涵盖桌面/移动端、语言持久化、旧请求竞态、权限、失败恢复、完整图片显示。前端构建、相关 ESLint 与后端 Ruff 检查通过。
