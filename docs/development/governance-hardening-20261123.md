# 治理修正与验收（2026-11-23）

## 范围

1. 默认后端镜像不再运行 `seed.py --check`。该命令实际上写入两遍演示数据，只能由 CI 或明确的本地演示导入使用。`scripts/start-local.ps1` 及其既有数据卷保留；默认 Compose 所有已发布端口绑定127.0.0.1。
2. 私聊正文与预览、举报说明、处罚/申诉正文、内部审计理由、见面地点和备注直接显示原文，界面文案仍支持中英文。公开商品标题/简介仍可本地翻译。翻译服务不写 SQLite；最多2000条内存缓存，服务启动时删除旧 `translations-<12位哈希或v版本号>.sqlite3` 及对应WAL/SHM/journal文件，仅限翻译缓存目录，保留模型和业务数据。历史备份副本不自动遍历删除。
3. 禁用用户时保留订单、消息和成交记录。早期订单通知正常一方取消；已确认见面或任意一方已确认完成的订单变为DISPUTED，并通知双方。已完成或已取消订单不改写。禁用对方后不能继续变更见面或确认成交。
4. 管理员仅能取消争议订单，须填写核实理由并提交当前订单版本；重复或陈旧提交409，无重复事件。保留双方完成确认原记录，追加取消事件和审计；通知双方。平台无支付退款能力，操作前必须确认线下物品/款项处理。取消不重新上架被删除/人工下架/卖家被封禁的商品，也不覆盖同商品的新订单。
5. 原处罚管理员不能复核或恢复自己的处罚。默认禁止；仅APP_ENV=dev、显式ALLOW_SINGLE_ADMIN_REVIEW=true且没有另一活跃管理员时允许演示例外，记录审计。另一个管理员复核仍可正常进行。账号恢复不会恢复旧登录凭证。T1/T2审计环境固定关闭例外。
