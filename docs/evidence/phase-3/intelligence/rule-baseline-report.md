## 指标口径

本报告属于 `RULE_ONLY_VALIDATION`，只说明固定规则用例通过，不是带真值标签的预测效果评估。当前没有合格 L3 完成交易标签，所以 `labeledPredictionMetrics=NOT_EVALUATED`，不得把挂牌价当成交真值，也不得宣称 MAE、MAPE、准确率或区间覆盖率。
