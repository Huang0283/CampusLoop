# MQ3-07 第三次汇报：十分钟真实MVP

预先准备：按README阶段三入口启动全栈，使用两个独立浏览器窗口（或普通+无痕）注册两个example.invalid虚构邮箱；使用本地产生PNG/JPEG，商品标题带当次唯一后缀。禁止真实个人资料、聊天隐私、未获许可图片。确认/ready，演示数据不能靠手改数据库生成。

0—1分钟：游客市场/求购可浏览，联系/发布要求登录；说明教学模拟邮箱域不是学籍认证。
1—3分钟：卖家发布标题/价格/图片/地点，买家搜索独有标题并读详情；收藏后回收藏列表。
3—5分钟：买家联系，两个窗口聊天；发送图片展示私有读取；买家报价，卖家接受，双方读取同订单。
5—7分钟：卖家建立未来日期约定并确认，买家确认同版本，显示双方确认；双方分别完成，商品SOLD、订单COMPLETED，时间线真实持久化。
7—8分钟：已完成订单评价；举报和通知已读，展示请求与页面更新，不展示证据文件内容给无关人。
8—9分钟：求购设置预算/地点/最低成色，展示真实规则匹配及原因；价格展示区间/免责声明。
9—10分钟：说明基础交易与智能建议解耦、当前限制、人工验收和后续Phase4模型比较。

备用：WS断开时明确显示恢复中并用HTTP发送/补拉；智能服务关闭时关键词/规则降级或价格不可用，不伪造成功。不在线更改源代码/数据库；全栈不可用则播放已有脱敏记录并明确是预录，不宣称现场通过。

刷新页面通过HttpOnly cookie安全恢复本人，服务端商品/交易数据保留；退出后重载不能恢复，令牌不写localStorage。此脚本已由自动化覆盖功能主路径，但真人10分钟演示计时未执行，需非作者实跑后记录实际时长。
