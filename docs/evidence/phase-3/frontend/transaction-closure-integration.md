# FE3-10 双方完成、评价与治理

双方完成按钮各提交自己的确认，只有双方完成后显示完成/评价入口；不以单方客户端点击为订单完成。评价含总体、描述、沟通、守时四评分，完成后按后端资格/唯一约束提交。

商品、用户、聊天消息、订单四举报类型统一ReportButton；私有evidence上传失败禁止提交，记录页读取真实reports/mine。通知列表/单条与全部已读采用真实API，链接限制内部路由，铃铛固定并可重试读取失败。/report为通知页中的本人举报记录，不是高级举报管理后台。

实际浏览器旅程完成双方确认→双方完成→评价→订单举报→通知全已读。私有举证/越权、非完成评价、重复评价由后端测试验证。其他三类型UI及单条已读请独立人工复测。
