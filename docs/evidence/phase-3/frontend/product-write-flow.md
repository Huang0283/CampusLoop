# FE3-05 商品写入和上传

发布/编辑采用生成ProductWriteRequest，分类/成色为canonical枚举；读取的历史字符串不直接强制当写入值，未知历史值要求所有者重新选择。清空可选原价发送null，避免旧原价不能删除。

ImageQueue校验JPEG/PNG和5MiB，逐个显示进度、错误/重传，上传未结束或失败时禁止保存。已保存图片在编辑时保留，删除队列条目仅从待提交列表移除；后端确认上传元数据所有权。真正成功响应后进入/product/{id}。

我的发布可编辑、上/下架和逻辑删除；RESERVED/SOLD禁止普通编辑/状态写入，不绕过交易状态机。

复验：上传有效PNG后保存，另一账号读取；错误扩展/伪图片不产生商品；上传失败阻止提交，恢复重传；编辑删除原价/移除一图并保存；同一创建键重试无重复商品。实际浏览器已覆盖有效上传，坏图片/权限/幂等由接口测试覆盖，其余编辑细节请独立人工复测。
