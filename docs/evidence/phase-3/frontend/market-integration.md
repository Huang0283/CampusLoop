# FE3-04 市场真实数据

`MarketPages.tsx`列表/详情/我的发布/收藏全部读取后端。公开搜索关键词调用/search，无关键词列表调用/products；分类、成色、排序和页码存在URL中，进入商品后返回市场保留条件。收藏分页读取后端，不存本地业务事实。

无初始数据使用“暂无内容”，有筛选但无结果使用“没有符合筛选条件的结果”；服务故障显示重试而非空列表。筛选变化回到第一页。游客可读市场商品，写操作引导登录。

复验：发布带唯一标题商品，另一账号搜索找到并打开；刷新后重登仍可检索同一ID；收藏/取消后重新读取列表；使用不可能匹配的关键词看到筛选空态。浏览器真实发布搜索旅程与移动空态用例已覆盖。
