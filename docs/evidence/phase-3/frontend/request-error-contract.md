# FE3-03 唯一HTTP入口与错误边界

生产页只调用`frontend/src/sdk/index.ts`导出的生成SDK，基础URL来自VITE_API_BASE_URL。生成目录来自openapi/campusloop.v1.yaml；不能手写生成文件。

请求使用10秒超时、调用者AbortSignal、页面卸载取消。错误包含安全code/requestId；不记录密码、令牌、邮箱、私聊或举报附件。网络失败、401、403、422、429、5xx保留不同错误码；403页面明确无权，401在刷新失败为未授权时清理身份并重登，422保持表单可改。

只对401做一次刷新后重发；业务500不自动重试。刷新网络/5xx失败保留内存令牌便于恢复，不把暂时服务故障当退出。创建类请求使用同一负载的稳定Idempotency-Key；编辑负载后换键。发送消息重试保持clientMsgId。

复验：断开API触发网络错误，恢复后点重试；过期凭据/禁用/无权/错误表单按后端测试请求验证。浏览器已实际注入断网与消息POST失败；所有错误类别的逐页人工复测不冒充已执行。
