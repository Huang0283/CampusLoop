# FE3-06 求购、规则匹配和价格

求购列表、详情、发布/编辑/关闭、匹配结果来自真实API。预算、最低成色、地点、时区到期时间进入后端硬约束；datetime-local输入转换ISO时区，编辑还原本地显示。

匹配展示真实商品、逐项原因、规则相关度，明确“不是成交概率”；服务降级显示warning和原因。已关闭/到期求购不展示新有效匹配，只有所有者访问匹配接口。

规则价格展示上下界、因素、免责声明/版本；无足够数据/服务不可用显示不可用，不编造单价。Phase3不实现语义模型或高级价格模型。

浏览器wanted/price用例验证真实提交和规则区间；test_live_intelligence验证硬约束、所有者、关闭服务降级与可信事件口径。人工验收将预算缩至不可能区间并检查零违规候选。
