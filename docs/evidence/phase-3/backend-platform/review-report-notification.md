# BP3-08 评价、举报、通知

评价只接受完成订单参与者，overall/descriptionAccuracy/communication/punctuality 四维均 1–5，评价对象从订单推导，每方每订单唯一，幂等重试不多计事实。公开信誉与评分排除取消/争议/未完成订单。

四类举报 USER/PRODUCT/ORDER/CHAT_MESSAGE：对象存在、私有对象参与者资格、当前用户上传的私有举证引用及请求幂等均校验。普通用户只能读取自己举报的状态摘要，无举证全文或图片。高级处理/处罚属于下一阶段，不以自动风险规则处罚。

通知仅收件人读取/标记，已读重复无副作用；聊天与订单通知随事实同事务提交，重复消息/确认不多通知。匹配自动通知已实现唯一 pair 键，但默认关闭、待政策确认。测试涵盖私有图片、举报权限、收藏与求购、读游标及双账号流程。
