# BP3-06 报价与原子订单

报价创建、接受/拒绝、还价/撤回均按 proposer 身份与 PENDING/有效期约束。还价产生新报价并翻转 proposer，不改变原买卖身份。接受在一个事务内更新报价、预订商品、创建唯一订单、订单事件及通知；客户端不能自指定参与者或成交状态。

锁顺序：用户/会话授权→商品→报价→订单→约定。数据库唯一 offer_id 和有效商品订单局部唯一索引保护双卖；同幂等键同内容返回保存结果，同键异内容 409。前端同一未知结果重试保持键，改动表单内容换键。

验证 test_transaction_api.py：双请求并发接受仅一个有效订单；人工注入通知失败后报价 PENDING、商品 ON_SALE、订单不存在，重试可成功；不得将故障测试注入当作运行时 Mock。
