# FE2-11 页面五态矩阵

本文件登记 M2、M3 的既有页面，并由集中收尾补充 M4 页面。覆盖登记不代表另一成员 Review、M10 签收或跨组验收已完成。

## M3 验收结论

- M3 页面均有实现状态或具体不适用理由。
- 公开浏览和登录后动作已分离。
- 商品与求购管理在 Phase 2 使用持久化 Mock，真实接口替换留给 Phase 3。
- M4 页面已在下文补充；全组门禁仍等待同一集成提交的人工验收。

## M2：公共壳层、认证、资料与管理入口

| 页面 | 加载 | 空 | 成功 | 失败 | 无权限 / 不适用理由 |
| --- | --- | --- | --- | --- | --- |
| `/` | 不适用：无数据请求 | 不适用：无页面内容 | 立即重定向至公开市场 `/market` | 不适用：静态路由重定向 | 公开入口，不执行权限判断 |
| `/login` | 提交期间按钮 loading，表单和演示状态禁用 | 不适用：认证表单始终存在 | 学生进入来源页或 `/market`，管理员进入来源页或 `/admin` | 可演示凭据错误、令牌失效和账号禁用，均留在当前页显示反馈 | 公开页面；学生请求管理员来源时不会进入 `/admin` |
| `/register` | 提交期间按钮 loading，表单禁用 | 不适用：注册表单始终存在 | 注册成功提示后返回 `/login` | 字段校验、两次密码不一致和邮箱已注册均有反馈 | 公开页面，不存在无权限状态 |
| `/profile` | Phase 2 使用同步 Mock 身份，不执行远程加载；Phase 3 接口接入后使用公共 `PageState` | 用户资料字段为空时以 `-` 或空表单表达，不把账号误判为不存在 | 显示当前身份、校园认证状态和资料；保存后更新 Mock 身份并提示成功 | Phase 2 无远程保存失败；已在 `page-api-map.md` 登记为 Phase 3 必补状态 | 未登录由 `RequireAuth` 保存完整来源并跳转 `/login` |
| `/admin` | Phase 2 使用同步 Mock 表格，不执行远程加载；Phase 3 接口接入后使用公共 `PageState` | 搜索无结果时 Ant Design Table 显示空数据 | 管理员可查看标签页、搜索和分页原型 | Phase 2 无远程接口失败；真实管理操作和错误反馈留给 Phase 3 | 未登录进入 `/login`；普通学生由 `RequireRole` 进入 `/403` |
| `/403` | 不适用：静态结果页 | 不适用：页面本身即权限结果 | 显示 403 说明并提供返回首页入口 | 不适用：无数据请求 | 专门承载无权限状态，页面自身公开可达 |
| `/404` | 不适用：静态占位页 | 不适用：页面本身即未找到结果 | 显示 Not Found 占位；未知路由统一重定向到此页 | 不适用：无数据请求 | 公开系统页，不执行角色判断 |

## M2 验收结论

- M2 负责页面的五列均有当前实现或具体不适用理由。
- 登录成功、凭据错误、令牌失效、账号禁用、来源路径恢复、普通用户访问管理员页均已有可点击入口。
- `/profile` 和 `/admin` 的远程加载/失败状态明确留给 Phase 3 真实接口接入，不把同步 Mock 描述成真实 API。
- M4 页面已在下文补充；全组门禁仍等待同一集成提交的人工验收。

## M4：聊天与交易治理（集中收尾登记，无表格）

### `/chat`

- 加载：同步 Mock 会话列表无远程请求，不适用；Phase 3 加 HTTP 读取状态。
- 空：当前身份无参与会话或筛选无结果时显示列表空态。
- 成功：进入参与的会话，显示上下文及未读。
- 失败：同步 Mock 无加载失败；真实 HTTP 失败留给 Phase 3。
- 无权限：学生路由守卫限制登录和角色；列表按参与关系筛选。

### `/chat/:id`

- 加载：读取历史时 `Loading`。
- 空：无消息时 `EmptyState`；不存在/非参与会话不给出私密内容。
- 成功：消息与报价展示、发送、重发、补拉和上下文跳转。
- 失败：`ErrorState` 与重试、失败消息重发、断线/重连提示。
- 无权限：当前学生必须是会话参与者。

### `/transactions` 与 `/transactions/:id`

- 加载：列表预留 Skeleton 状态但当前同步 Mock 不自动触发远程加载；详情同步读取不适用；写动作按钮显示模拟提交 loading。
- 空：列表无参与订单/筛选无结果；不存在详情显示未找到。
- 成功：列表筛选、详情、事件时间线、状态决定的角色动作。
- 失败：列表提供“切换失败状态”与 `ErrorState` 重试；真实 HTTP 失败留给 Phase 3；被拒绝的状态/身份动作不修改内存，报价页面明确提示拒绝原因。
- 无权限：学生路由守卫；列表和详情均限制参与关系。

### `/transactions/:id/meetup`

- 加载：同步订单读取不适用；保存按钮有提交 loading。
- 空：未填写约定时提示填写，不存在订单显示未找到。
- 成功：保存新版本、确认当前版本、展示真实变更事件。
- 失败：字段校验或状态层拒绝保留表单并提示，不伪造保存成功。
- 无权限：仅参与方可查看；终止/争议态表单不展示。

### `/transactions/:id/review` 与评价弹窗

- 加载：同步 Mock 不适用；Phase 3 替换真实写入时添加提交 loading。
- 空：默认空评论，评分默认或必填；无订单返回未找到。
- 成功：完成订单参与方保存一次有效评价。
- 失败：非法评分、重复评价、状态变化拒绝提交并提示。
- 无权限：第三人、未完成/取消订单不能进入可提交评价。

### `ReportModal`（用户/商品/订单/消息四类）

- 加载：Phase 2 文件仅本地校验，无上传等待；Phase 3 添加上传/提交 loading。
- 空：无文件合法，原因必填；可关闭弹窗放弃。
- 成功：保存本地目标/原因/证据文件名，明确 Mock 提示。
- 失败：缺少原因、说明过长、格式/大小错误显示校验提示，违规文件不加入列表。
- 无权限：公开页面用统一登录动作守卫；私有会话/订单入口在参与关系检查后展示。

### `/notifications`

- 加载：同步内存 Mock，不适用；Phase 3 添加 HTTP 状态。
- 空：当前身份无通知或筛选无结果显示空列表。
- 成功：分类、上下文跳转和当前接收人单条/全部已读。
- 失败：Phase 2 无 HTTP 写入失败；真实失败与回滚在 Phase 3 补齐。
- 无权限：学生路由守卫；按 recipientId 限定可读可写数据。
