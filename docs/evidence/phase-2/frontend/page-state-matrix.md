# FE2-11 页面五态矩阵

本文件由 M2、M3、M4 共同维护，已登记 M2、M3 的页面；M4 必须在其任务 PR 中追加页面，不能把本文件存在理解为 FE2-11 全组完成。

## M3：市场、商品与求购

| 页面 | 加载 | 空 | 成功 | 失败 | 无权限 / 不适用理由 |
| --- | --- | --- | --- | --- | --- |
| `/market` | Mock 延迟显示 Spin | 筛选无结果显示 Empty | 商品、筛选、排序、分页可用 | `marketMockLoadError` 显示错误和重试 | 公开页面，不因缺少 token 禁止浏览；私有动作进入登录 |
| `/product/:id` | 接口/Mock 读取期间显示 Spin | 非法或不存在 ID 显示未找到 | 详情、收藏、联系、举报入口可用 | 接口失败且无同 ID Mock 时显示错误 | 公开页面；收藏、联系和举报由动作守卫处理 |
| `/publish` | 提交和图片队列显示 loading | 空表单通过字段校验表达 | Mock 创建后进入我的发布 | 上传/提交失败保留表单与草稿 | 受保护路由，未登录保存来源后进入登录 |
| `/product/:id/edit` | 初始化后回填 Mock 商品 | 不存在 ID 提示并返回我的发布 | 保存后保持商品 ID/状态/创建时间 | 提交失败保留修改与草稿 | 受保护路由 |
| `/my-products` | Mock 延迟显示 Spin | 无商品或搜索无结果显示 Empty | 编辑、上下架、删除可点击 | `myProductsMockLoadError` 显示错误和重试 | 登录后页面，缺 token 显示无权限兜底 |
| `/favorites` | Mock 延迟显示 Spin | 无收藏或筛选无结果显示 Empty | 搜索、筛选、排序、取消收藏可用 | `favoritesMockLoadError` 显示错误和重试 | 登录后页面，缺 token 显示无权限兜底 |

| `/wanted/:id` | 接口/Mock 读取期间显示 Spin | 非法或不存在 ID 显示未找到 | 详情、联系、举报、匹配入口可用 | 接口失败且无同 ID Mock 时显示错误 | 公开页面；私有动作由动作守卫处理 |

| `/publish/price-advice` | 静态原型，不适用并登记 | 数据不足显示不可用说明 | 显示区间、因素和免责声明 | 智能不可用应保持手动定价，不阻塞发布 | 受保护路由 |

## M3 验收结论

- M3 页面均有实现状态或具体不适用理由。
- 公开浏览和登录后动作已分离。
- 商品与求购管理在 Phase 2 使用持久化 Mock，真实接口替换留给 Phase 3。
- FE2-11 全组状态仍为未完成，直到 M4 追加其页面并通过 M10 验收。

## M2：公共壳层、认证、资料与管理入口

| 页面 | 加载 | 空 | 成功 | 失败 | 无权限 / 不适用理由 |
| --- | --- | --- | --- | --- | --- |
| `/` | 不适用：无数据请求 | 不适用：无页面内容 | 立即重定向至公开市场 `/market` | 不适用：静态路由重定向 | 公开入口，不执行权限判断 |
| `/login` | 提交期间按钮 loading，表单和演示状态禁用 | 不适用：认证表单始终存在 | 学生进入来源页或 `/market`，管理员进入来源页或 `/admin` | 可演示凭据错误、令牌失效和账号禁用，均留在当前页显示反馈 | 公开页面；学生请求管理员来源时不会进入 `/admin` |
| `/register` | 提交期间按钮 loading，表单禁用 | 不适用：注册表单始终存在 | 注册成功提示后返回 `/login` | 字段校验、两次密码不一致和邮箱已注册均有反馈 | 公开页面，不存在无权限状态 |
| `/profile` | Phase 2 使用同步 Mock 身份，不执行远程加载；Phase 3 接口接入后使用公共 `PageState` | 用户资料字段为空时以 `-` 或空表单表达，不把账号误判为不存在 | 显示当前身份、校园认证状态和资料；保存后更新 Mock 身份并提示成功 | Phase 2 无远程保存失败；已在 `page-api-map.md` 登记为 Phase 3 必补状态 | 未登录由 `RequireAuth` 保存完整来源并跳转 `/login` |
| `/admin` | Phase 2 使用同步 Mock 表格，不执行远程加载；Phase 3 接口接入后使用公共 `PageState` | 搜索无结果时 Ant Design Table 显示空数据 | 管理员可查看标签页、搜索和分页原型 | Phase 2 无远程接口失败；真实管理操作和错误反馈留给 Phase 3 | 未登录进入 `/login`；普通学生由 `RequireRole` 进入 `/403` |
| `/403` | 不适用：静态结果页 | 不适用：页面本身即权限结果 | 显示 403 说明并提供返回首页入口 | 不适用：无数据请求 | 专门承载无权限状态，页面自身公开可达 |
| `/404` | 不适用：静态占位页 | 不适用：页面本身即未找到结果 | 显示 Not Found 占位；未知路由统一重定向到此页 | 不适用：无数据请求 | 公开系统页，不执行角色判断 |

## M2 验收结论

- M2 负责页面的五列均有当前实现或具体不适用理由。
- 登录成功、凭据错误、令牌失效、账号禁用、来源路径恢复、普通用户访问管理员页均已有可点击入口。
- `/profile` 和 `/admin` 的远程加载/失败状态明确留给 Phase 3 真实接口接入，不把同步 Mock 描述成真实 API。
- FE2-11 全组仍为未完成，直到 M4 追加其页面并由 M10 在同一阶段提交验收。
