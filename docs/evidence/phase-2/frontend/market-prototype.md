# FE2-05 市场连续可点击原型

## 范围

- 公开页面：`/market`、`/product/:id`。
- 登录后动作：收藏、联系卖家、举报、发布商品和查看个人收藏。
- 页面访问与动作权限分开处理：游客可以浏览列表和详情，点击登录后动作时保存当前地址并进入 `/login`。

## 页面与契约映射

- 商品列表和分类、价格、成色、地点、排序控件保留为 Phase 2 可点击 Mock，不声称已完成真实接口联调。
- `/market` 不再以 token 作为浏览前置条件；游客与登录用户均可查看同一份 Phase 2 Mock 商品。
- `/product/:id` 优先读取公开详情接口；接口在 Phase 2 验收环境不可用时，对市场 Mock 商品进行同源回退，确保详情、收藏动作守卫和登录回跳不依赖后端进程。
- 商品详情调用 `GET /products/{productId}`，路由参数 `:id` 映射为契约参数 `productId`。
- 收藏和取消收藏分别调用 `PUT /favorites/{productId}`、`DELETE /favorites/{productId}`。
- 联系卖家进入受保护的聊天入口；创建具体会话仍由后续聊天接口任务实现。
- 举报沿用统一 `ReportModal` 原型；游客必须先登录，Phase 3 再替换为真实举报接口。

## 连续操作场景

1. 游客进入 `/market`，使用分类、价格、成色、地点和排序控件浏览卡片。
2. 点击商品卡片进入 `/product/:id`，详情页读取路由 ID 并请求公开详情接口。
3. 从详情页返回市场不触发登录。
4. 游客点击收藏、联系卖家或举报时进入登录页；登录成功后返回原详情地址。
5. 已登录用户收藏成功后按钮切换为取消收藏；接口失败时按钮状态不提前改变。

## 页面状态

- 加载：详情接口请求期间显示加载状态。
- 空状态：路由 ID 无效或商品不存在时显示空状态。
- 错误：网络或服务错误显示可理解的错误提示。
- 无权限：公开读取不因缺少 Token 失败，受保护动作由动作守卫处理。
- 成功：详情、收藏切换和举报弹窗均有明确反馈。

## 阶段边界

Phase 2 验收页面流程、动作权限和接口映射；商品列表真实查询、聊天会话创建、举报持久化及端到端数据一致性属于 Phase 3。
