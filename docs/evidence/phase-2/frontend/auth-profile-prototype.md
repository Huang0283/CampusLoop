# 认证与资料可点击原型（FE2-02）

## 1. 范围和地址

- 登录：`http://localhost:5173/login`
- 注册：`http://localhost:5173/register`
- 资料：`http://localhost:5173/profile`
- 管理入口：`http://localhost:5173/admin`
- 无权限：`http://localhost:5173/403`

本阶段使用 `localStorage` 中明确标识的演示身份，不调用真实认证接口。真实注册、登录、刷新、退出和资料接口由 FE3-01/FE3-02 接入。

## 2. 可复现状态

登录页的“演示状态”可以直接选择以下状态：

1. 正常：选择学生或管理员，提交后建立演示身份；学生默认进入 `/market`，管理员默认进入 `/admin`。
2. 凭据错误：停留登录页，显示“邮箱或密码错误”，不写入身份。
3. 令牌失效：清除演示 token，停留登录页并显示重新登录提示。
4. 账号禁用：停留登录页，显示账号禁用及联系管理员提示，不写入身份。

注册页支持成功和邮箱已注册错误；资料页支持昵称、头像及公开资料编辑；用户菜单支持退出并清除本地演示身份。

## 3. 权限和回跳

- 游客可以浏览 `/market`、`/product/:id`、`/wanted`、`/wanted/:id`。
- 游客直接访问私有页面时进入 `/login`，登录后返回原地址。
- 返回地址完整保存 `pathname`、查询参数和锚点。例如从 `/market?keyword=book#results` 触发受保护动作，登录后仍返回该地址。
- 普通用户进入 `/admin` 时进入 `/403`；管理员可以进入后台。
- 公开页面上的受保护动作由 `useRequireAuthAction` 统一处理。M3/M4 必须在各自页面任务 PR 中接入，M2 不跨越页面所有权直接修改业务页面。

## 4. 手动验收步骤

1. 打开 `/login`，依次选择四种演示状态并提交，确认成功、失败、失效和禁用提示互不混淆。
2. 未登录打开 `/profile`，确认跳转登录；正常登录后确认返回 `/profile`。
3. 未登录打开带查询参数和锚点的受保护地址，正常登录后确认查询参数和锚点未丢失。
4. 以学生身份打开 `/admin`，确认进入 `/403`；退出后以管理员身份登录，确认进入 `/admin`。
5. 编辑 `/profile` 后刷新，确认 Phase 2 演示资料仍可恢复；退出后确认身份清理。

## 5. Phase 3 替换边界

- M5 / BP2-01 提供认证成功、凭据错误、过期、禁用和越权契约样例。
- M2 / FE3-01 用生成 SDK 替换演示登录、注册、刷新和退出。
- M2 / FE3-02 用 `/users/me` 替换本地资料，并落实字段可见性。
- M2 / FE3-03 统一处理 401、403、422、网络错误和重试边界。
