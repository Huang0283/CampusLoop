## 3.1 路由 Owner 与来源恢复

| 路由范围 | 页面 Owner | 共享守卫 Owner | 登录后的返回规则 |
|---|---|---|---|
| `/login`、`/register`、`/profile`、`/admin`、`/403`、`/404` | M2 | M2 | 私有来源恢复完整 `pathname + search + hash` |
| `/market`、`/product/*`、`/publish*`、`/my-products`、`/favorites` | M3 | M2 | 浏览保持原地址；私有动作登录后回到触发页 |
| `/wanted*` | M3 | M2 | 浏览保持原地址；发布/匹配/私有动作登录后回到触发页 |
| `/chat*`、`/transactions*`、`/notifications`、`/report*` | M4 | M2 | 私有页面登录后回到原地址 |

`RequireAuth` 负责私有页面，`RequireRole` 负责管理员角色，`useRequireAuthAction` 负责公开页面中的私有动作。M3/M4 不得在业务页面复制登录判断。

## 4. 默认跳转

| 场景 | 跳转 |
|---|---|
| 访问 / | → /market（公开，可浏览） |
| 未登录访问「登录用户」页面 | → /login（带 state.from 回跳） |
| 未登录访问 /admin | → /login |
| 已登录非管理员访问 /admin | → /403 |

## 5. 移动端入口

- 桌面端：顶部导航 + 左侧侧边栏
- 移动端：`MobileNav` 底部导航栏，包含：首页、求购、聊天、交易
- 个人中心在右上角头像菜单
- 小于等于 640px 时隐藏桌面侧边栏并显示底部导航，内容区保留底部安全空间
