# FE2-06 商品发布与管理原型

## 范围

- 发布入口：`/publish`，由路由登录守卫保护。
- 编辑入口：`/product/:id/edit`，复用商品表单页面并保持受保护状态。
- 个人商品入口：`/my-products`，用于承接编辑、上下架和删除确认原型。

## 发布流程

1. 用户填写标题、分类、成色、原价、售价、描述和交易地点。
2. 图片选择后逐张调用 `POST /uploads/images`；只接受 JPG/PNG，最多五张。
3. 上传中的图片会阻止提交；没有任何成功上传的图片也会阻止提交。
4. 上传成功返回的 URL 写入商品创建请求。
5. 提交 `POST /products` 时生成新的 UUID 作为 `Idempotency-Key`，并在请求完成前禁用重复提交。
6. 成功后进入 `/my-products`；失败时保留表单并显示后端错误或统一错误提示。

## 异常与反馈

- 格式错误：选择阶段直接拒绝非 JPG/PNG 文件。
- 数量超限：上传组件限制为五张。
- 大小超限：由上传接口 `413` 响应决定，前端展示接口错误；在 M6 冻结具体大小前不虚构阈值。
- 上传失败：单张图片标记失败，失败图片 URL 不进入商品请求。
- 字段校验失败：由表单定位到具体字段。
- 重复提交：按钮 loading 与幂等键共同处理。
- 未登录：路由守卫保存来源并跳转登录。

## 管理动作边界

编辑、上下架和删除确认在 Phase 2 验收可点击状态和确认反馈；真实 `PATCH/DELETE`、版本冲突和持久化结果在 Phase 3 接口联调中验收。
