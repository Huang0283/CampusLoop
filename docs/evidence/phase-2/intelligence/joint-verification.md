2. M8 原 `verify` 会覆盖原派生文件，只比较重建结果，无法识别先前被篡改的派生文件。联合流程改为发布 schema 校验及两个临时目录重建，并对比原文件哈希；篡改测试确认失败后不修复原文件。
3. 旧检出在 Windows autocrlf=true 下将 M8 JSON 换成 CRLF，原文件与临时重建字节不同。新增路径属性保护；原检出恢复 Git 提交字节，未修改 M8 数据、规则或 manifest 内容。随后在 true/false 两次干净检出实测。
4. 仅填成交金额/时间不足以让合成来源变成真实成交标签。联合准入拒绝 synthetic 来源携带 L1/L2/L3 标签；当前 12 条合法 L0 保持原样。
5. 文档中的数据版本引用与 manifest 不一致；当前文档已统一为 `m7-synthetic-p2-v1.1`。候选集没有改写成封存 test，签字仍为空。
6. 原运行器只保存输出尾部且依赖系统默认编码。现保存完整 UTF-8 日志、源码及数据哈希、真实起止时间、命令与错误码，检查前后资产不变并设置显式分项超时。
