# AI2-10 Phase 4 模型启用门槛

## 规则

以下数值是看最终模型结果之前登记的候选门槛。任何门槛空白、固定评估集未封存、人工标签不足、独立复现失败或规定签字缺失，对应模型均自动 `NO-GO`，继续使用 Phase 3 关键词/规则/手动降级。门槛不得在看到结果后下调。

## 语义搜索

- 固定评估集：`m7-p2-data-v1.1` 经人工复核并冻结的 test 集；至少 100 个已复核查询，每个报告切片至少 30 个查询。
- 主门槛：`MRR >= 0.65`，`Recall@10 >= 0.80`，`Precision@5 >= 0.70`。
- 相对门槛：同一集合相对关键词基线 MRR 至少提升 10%；任何主要切片 Recall@10 不得下降超过 5 个百分点。
- 性能：单请求 p95 <= 300 ms、p99 <= 600 ms；服务 RSS <= 512 MiB；模型/索引新增磁盘 <= 1 GiB（统一 Phase 4 环境）。
- 必测降级：模型缺失、加载失败、超时、空查询和向量库不可用时回退关键词；交易/浏览不被阻塞。
- 决策签字：M7、M10、M1；当前均 `PENDING`，所以当前状态 `NO-GO`。

## 供需匹配

- 固定评估集：`m7-p2-data-v1.1` 经人工复核并冻结的 matching test；至少 100 个请求，每个报告切片至少 30 个。
- 主门槛：`MRR >= 0.65`，`Recall@10 >= 0.80`，硬约束违规率必须为 0。
- 相对门槛：相对纯规则基线 MRR 至少提升 10%；任何主要切片 Recall@10 不得下降超过 5 个百分点。
- 性能：异步单任务 p95 <= 500 ms、p99 <= 1 s；RSS <= 512 MiB；新增磁盘 <= 1 GiB。
- 必测降级：模型不可用时只按已知硬约束返回规则结果；重复事件结果确定、通知不重复、过期求购不触发。
- 决策签字：M7、M10、M1；当前均 `PENDING`，所以当前状态 `NO-GO`。

## 价格候选模型

- 固定评估集：未来由批准的 L3 完成交易记录形成 `m8-price-l3-test-v1`；总体至少 200 条，每个用于通过/失败判断的类别或价格段至少 30 条。
- 主门槛：`NMAE = MAE / 测试集成交价中位数 <= 0.20`；同时 `MAPE <= 25%`。
- 区间门槛：完成交易价覆盖率 >= 80%，平均归一化区间宽度 <= 0.60；不得以任意加宽区间换覆盖率。
- 相对门槛：候选模型相对 `price-rule-v1.0-phase2` 的 NMAE 至少改善 10%；任何达到 30 条的主要切片 NMAE 不得恶化超过 5 个百分点。
- 性能：单请求 p95 <= 300 ms、p99 <= 600 ms；服务 RSS <= 512 MiB；模型包 <= 200 MiB。
- 必测降级：数据不足、未知类别、缺模型文件、加载失败、超时、版本不匹配时回退规则区间或手动定价；发布流程不被阻塞。
- 数据质量：真实 L3 为 0 或未取得 M5/M6 授权与事实确认时，不计算/发布上述指标，模型自动 no-go。
- 决策签字：M8、M10、M1。M8 候选门槛已填写；M10/M1 均 `PENDING`，所以当前状态 `NO-GO`。

## 信誉与风险

Phase 4 不启用“信誉模型”或“欺诈概率模型”。只允许版本化规则：

- 公开信誉事实一致率必须 100%，新用户伪评分率必须 0。
- 公开风险字段泄漏必须 0；风险规则自动处罚次数必须 0。
- 风险重复事件去重率必须 100%；人工审核可追溯率必须 100%。
- 服务异常时举报仍可持久化，浏览、发布、聊天和交易不被阻塞。

任何不满足均为 no-go，且不能通过调整阈值绕过权限边界。
