## 信誉与风险

Phase 4 不启用“信誉模型”或“欺诈概率模型”。只允许版本化规则：

- 公开信誉事实一致率必须 100%，新用户伪评分率必须 0。
- 公开风险字段泄漏必须 0；风险规则自动处罚次数必须 0。
- 风险重复事件去重率必须 100%；人工审核可追溯率必须 100%。
- 服务异常时举报仍可持久化，浏览、发布、聊天和交易不被阻塞。

任何不满足均为 no-go，且不能通过调整阈值绕过权限边界。

## 签字表

MRR 相对改善为 `(candidate - baseline) / baseline`；NMAE 相对改善为 `(baseline - candidate) / baseline`。基线为 0 时相对改善记 N/A，不能自动通过相对门槛；替代规则须在模型开发和最终测试前由决策人另行登记。两个方案必须使用相同封存数据、身份、snapshot、过滤、K 和排除清单。目录候选池的 Recall 不能冒充全库 Recall；正式评估的候选范围尚待确认。
