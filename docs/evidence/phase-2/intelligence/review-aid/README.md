# 人工复核辅助表（去锚定版）

本目录保留用户指定的复核辅助表，供后续补录与核对。仓库中 CSV 保持用户文件原字节；独立输出目录中的辅助表仍不纳入交付 ZIP 或 `FILES.sha256.json`，也不替代 AI2-02 的人工签字。

## 文件

- `human-review-sheet.csv`：228 对标签的去锚定复核表。已隐藏候选标签、候选理由和逐项硬约束判定，只保留 query、筛选条件、商品事实，末尾留空白复核列。

## 为什么要隐藏候选标签

文档 `search-labeling-record.md` 建议：独立初判时先隐藏 `candidateLabel/candidateReason`，复核人先按 query、filters、商品事实独立填自己的标签，再展开对照，避免锚定偏差。本表就是为此生成的。

## 怎么用

1. 复核人在 `reviewer` 填真实姓名/标识，`reviewLabel` 填 2/1/0/U，`reviewReason` 填一句理由，`reviewedAt` 填时间。
2. 先整批独立判完，再对照 `data/m7-phase2/derived/review-queue.csv`（含 `candidateLabel/candidateReason/constraintChecks`）。**不要直接把候选列复制为通过。**
3. 有分歧的在 `dispute` 标注，由裁决者按业务事实填 `adjudicator/finalLabel/adjudicatedAt`。

## 标签定义

| 标签 | 含义 |
| --- | --- |
| 2 | 明确对应所求型号/版本，且没有硬条件失败或未知 |
| 1 | 相关但不完全符合文本目标（如同类不同型号、未设型号硬条件） |
| 0 | 不相关，或任一硬条件失败（即使文字高度相似） |
| U | 关键硬条件未知且没有其他已知失败 |

硬条件：求购有效、商品在售未删除、可见性、非本人、分类、预算、最低成色、必需地点、必需型号。
