# MQ2-06 权限、隐私、状态与重复请求矩阵

> Owner：M10
> 日期：2026-09-29
> 规则：每个关键写操作至少覆盖成功、未认证/越权、非法状态和重复请求。

## 通用断言

- 未认证：`401`，不创建/修改任何事实。
- 已认证但无权：`403` 或不泄漏资源存在性的 `404`。
- 非法前置状态/版本/幂等冲突：`409`。
- 非法字段：`422`；错误响应不得包含堆栈、密码、Token 或私有字段。
- 重复请求：返回同一事实或确定冲突，不能创建第二条业务事实。

## 认证与资料写操作

### 注册

- 成功：新邮箱 `201`，一名用户和一份会话。
- 越权：不适用，原因是公开入口；但客户端不能提交 role/status 获得管理员权限。
- 非法：重复邮箱 `409`，弱/缺失字段 `422`。
- 重复：相同请求不得创建多个用户。

### 登录/刷新/退出

- 成功：正确凭据建立/轮换/撤销会话。
- 越权：伪造或他人 refresh token `401`。
- 非法：禁用 `423`，过期/撤销 `401`。
- 重复：旧 refresh token 重放失败；重复退出不恢复会话。

### 更新资料

- 成功：本人只更新允许字段。
- 越权：游客 `401`；修改他人 `403/404`。
- 非法：提交 role/status/email 等禁止字段 `422/403`。
- 重复：相同 PATCH 不产生额外审计或副作用。

## 商品、图片、收藏和求购

### 发布/编辑/删除商品

- 成功：本人合法数据和图片写入。
- 越权：游客 `401`；非本人 `403/404`。
- 非法：SOLD/删除商品编辑、非法金额/成色/类型 `409/422`。
- 重复：同一幂等键只生成一件商品；删除重复不生成第二事件。

### 上传图片

- 成功：允许 MIME、大小和数量进入公共桶。
- 越权：游客 `401`；私有举报桶不能通过商品接口写入。
- 非法：伪扩展名、不可解码、超限、超数量 `422/413`。
- 重复：同一内容/键策略明确，不覆盖他人对象。

### 收藏

- 成功：添加/移除本人收藏。
- 越权：游客 `401`；不能操作他人收藏。
- 非法：不存在/不可见商品按契约失败。
- 重复：唯一 `(user_id, product_id)`；重复添加/删除幂等。

### 求购创建/编辑/关闭

- 成功：本人 OPEN 求购按预算/有效期规则写入。
- 越权：游客 `401`；非本人 `403/404`。
- 非法：预算倒置、过期时间、CLOSED/EXPIRED 非法编辑 `422/409`。
- 重复：同一幂等请求只创建一条；重复关闭不重放通知。

## 聊天和交易

### 会话和消息

- 成功：合法买卖双方创建会话和消息。
- 越权：游客 `401`；第三方读写 `403/404`。
- 非法：自聊、无效商品/求购、关闭上下文非法发送。
- 重复：相同上下文会话唯一；`clientMsgId` 重放不重复消息。

### 报价创建与状态动作

- 成功：参与者按角色创建/接受/拒绝/还价/取消。
- 越权：非参与者、错误角色 `403/404`。
- 非法：过期、终态、金额越界、旧版本 `409/422`。
- 重复：相同幂等键只创建一次；终态动作重放不产生新订单。

### 接受报价与订单创建

- 成功：一个订单原子创建并占用商品。
- 越权：非卖家或非参与者拒绝。
- 非法：商品非 ON_SALE、报价非 PENDING、版本过期 `409`。
- 重复/并发：只有一个请求成功，唯一约束与事务结果一致。

### 约定保存/确认

- 成功：参与者保存 N+1 并确认当前版本。
- 越权：非参与者拒绝。
- 非法：已取消/完成订单、旧版本确认 `409`。
- 重复：相同版本重复确认不新增事件；修改必使旧确认失效。

### 完成确认、取消和评价

- 成功：双方独立完成；合法角色取消；完成后各评价一次。
- 越权：第三方、非参与者和错误角色拒绝。
- 非法：无有效约定完成、终态取消、未完成评价 `409`。
- 重复：重复确认/取消/评价不产生第二事实。

## 举报、通知和管理

### 举报

- 成功：用户提交允许目标、原因和私有证据。
- 越权：游客 `401`；普通用户读取他人证据拒绝。
- 非法：无效目标、原因、数量/大小超限 `422`。
- 重复：相同业务键按策略合并或明确返回已有记录。

### 管理审核

- 成功：ADMIN 对 PENDING/PROCESSING 举报写决定和原因。
- 越权：普通用户 `403`。
- 非法：终态再次处理、缺原因 `409/422`。
- 重复：同一决定不产生重复审计或重复通知。

### 通知已读

- 成功：本人单条/全部已读。
- 越权：游客 `401`；他人通知 `403/404`。
- 非法：不存在通知 `404`。
- 重复：重复已读保持同一时间语义，不新增通知。

## 智能任务边界

- 搜索/匹配只读取公开字段和授权上下文；伪造 ownerId/权限布尔值必须拒绝。
- 结果过期、混合版本、旧 epoch、重复事件和租约过期必须失败或重算，不能提交旧结果。
- 智能通知默认关闭；未配置阈值、冷却和每日上限时不能启用。
- 风险输出不能自动修改用户状态；价格输出不能自动修改商品价格。
