## 原型演示路径

前端启动：

```text
cd frontend
npm ci
npm run dev -- --host 127.0.0.1
```

演示地址：

- `http://localhost:5173/market`：游客搜索、筛选、商品详情。
- `http://localhost:5173/product/1`：游客浏览与私有动作登录门禁。
- `http://localhost:5173/wanted`：求购搜索、排序、分页。
- `http://localhost:5173/wanted/1`：求购详情和匹配入口。
- `http://localhost:5173/wanted/1/matches`：候选匹配解释和异常状态。
- `http://localhost:5173/login`：错误凭据、过期、禁用和来源恢复原型。
- `http://localhost:5173/chat`、`/transactions`、`/notifications`：交易相关 Mock；必须说明 M4 Phase 2 收尾仍待提交。

## 现场验收问题

- 游客为什么能浏览但不能收藏/联系？
- `401/403/404/409/422` 分别表达什么？
- 两个买家同时接受报价如何保证唯一订单？
- 约定修改后为什么旧确认失效？
- AI 超时或结果过期时用户还能做什么？
- 哪些内容是 Mock，哪些是可执行契约，哪些是真实运行？
