## 已确认的一致项

- 公共市场和求购读取允许匿名；私有动作要求登录。
- OpenAPI 文件路径与生成 SDK 入口明确。
- 前端 SDK/Lint/build 可在干净依赖安装后通过。
- 后端 OpenAPI 候选、模型枚举和迁移枚举的主要名称一致。

## 必须关闭的冲突

### MQC-001 canonical OpenAPI 不在后端组分支

- 影响：M6 无法在后端组 PR 中证明唯一契约；M9 模型可能引用前端分支的未冻结文件。
- 最终 Owner：M6。
- 动作：从最新组分支提交 `openapi/campusloop.v1.yaml`、生成 SDK、契约样例和差异说明。
- 截止：2026-09-30 18:00。
- 当前结论：阻塞 `BASELINE-1.0-FROZEN`，不阻塞原型继续开发。

### MQC-002 M5 认证字段与令牌规则缺失

- 影响：注册 nickname、校园认证、公开/私有资料、禁用和 Token 恢复测试无法冻结。
- 最终 Owner：M5。
- 动作：提交 BP2-01/02 三份文档及成功/失败样例。
- 截止：2026-09-30 18:00。

### MQC-003 求购 `MATCHED` 语义冲突

- 影响：M7 规定“匹配不关闭求购”，后端枚举包含 `MATCHED`，页面可能把它解释为终态。
- 最终 Owner：M6；共同确认：M3/M7。
- M1 候选决定：匹配结果不自动改变求购生命周期；若保留 `MATCHED`，只能表示“存在当前匹配结果”，仍允许继续接收候选，关闭必须显式执行。
- 截止：2026-09-30 18:00。

### MQC-004 商品生命周期与展示状态未分离

- 影响：`RESERVED/SOLD/HIDDEN` 同时承担交易和展示含义，取消订单后的恢复状态可能错误。
- 最终 Owner：M6；存储影响：M9。
- 动作：在状态契约中写明取消、争议、隐藏、逻辑删除和重新上架规则。
- 截止：2026-09-30 18:00。

### MQC-005 搜索/匹配响应与当前 OpenAPI 不一致

- 影响：M7 的 `degraded/resultVersion/expiresAt/null score/服务端分页` 没有进入当前 SDK。
- 最终 Owner：M6/M7；消费者：M3。
- 动作：同一 PR 批次更新 OpenAPI、样例、SDK 和页面状态，不允许混用两种语义。
- 截止：2026-10-01 12:00。

### MQC-006 图片数量和举报证据上限
