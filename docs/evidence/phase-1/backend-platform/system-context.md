## 2. 组件责任表（职责不重叠）

| 组件 | 唯一责任 | 明确不做 |
|---|---|---|
| 前端 React | 页面、路由、状态、Mock/SDK 数据源切换；不持有业务真相 | 不做权限最终裁决、不自行拼装后端字段 |
| FastAPI API | 唯一业务入口：权限校验、状态机转换、事务边界、幂等、错误结构、ApiEnvelope | 不做异步长任务（交 Worker）、不直接改文件系统 |
| PostgreSQL | 唯一事实来源：表、约束（唯一/检查/FK）、状态枚举、审计字段、pgvector 向量列 | 不做业务计算、不做跨服务调用 |
| Redis | 会话/令牌撤销名单、通知未读计数、限流计数、缓存视图；可丢数据（可重建） | 不存交易事实，不做唯一事实来源 |
| MinIO | 对象存储（S3 协议），保存 object key 与元数据。**双桶隔离**：`campusloop-public`（商品图片等可公开内容，匿名公共读）与 `campusloop-private`（举报举证等敏感对象，默认私有，禁止匿名访问） | 不做权限判断：公共桶仅放可公开内容；私有对象的取用由 API 校验身份后签发**短时效预签名 URL** |
| Worker（P4） | 求购匹配、价格建议、风险分析等耗时任务；只经 API 相同的模型层读写 | 不直接暴露 HTTP，不绕过模型层改库 |

## 3. 边界决策（候选，供 BP-P2 消费）

1. **模块化单体优先**：Phase 2/3 只有一个 FastAPI 进程 + 一个迁移目录，按领域分包（`app/models/`、后续 `app/api/routes/`），不拆微服务；Worker Phase 4 才引入，且与 API 共享模型层。
2. **降级边界**（与说明书一致）：
   - Redis 不可用 → 令牌改查库、未读数退化为查询计数，基础交易可用；
   - MinIO 不可用 → 图片上传/展示失败但文字交易可用；
   - pgvector/AI 不可用 → 语义搜索降级为关键词 `ILIKE` 搜索（契约已定义降级字段）；
   - WebSocket 不可用 → 前端退化为 HTTP 轮询 + `afterId` 补拉。
3. **同步优先**：Phase 2 ORM 用同步引擎；异步在 Phase 3 引入 WebSocket 时再评估，避免双份连接管理。
4. **迁移唯一入口**：结构变更一律 Alembic revision + downgrade，禁止手改。
5. **对象存储双桶隔离（权限边界，公开与私有不混用）**：
   - `campusloop-public`：仅存商品图片等**可公开**内容，桶策略允许匿名 `download`，前端经 `S3_PUBLIC_BASE_URL` 直接拼接访问；
   - `campusloop-private`：存举报举证证据等**敏感对象**（`reports.evidence` 引用的 object key 一律指向此桶），桶保持默认私有、禁止匿名读取，访问必须经 API 权限校验（举报人本人/管理员/处理人）后签发**短时效预签名 GET URL**（有效期分钟级）；
   - 两桶由 Compose 初始化容器创建；公共读策略**只**作用于 public 桶，绝不整站单桶公共读。
