# MQ1-07 核心验收场景

详细场景见 [`docs/management/m10/acceptance-scenarios.md`](../../../management/m10/acceptance-scenarios.md)。每个场景采用 Given/When/Then，至少覆盖一个正向和一个异常/权限结果。
