# MQ1-05 十周计划与阶段门禁

详细周计划见 [`docs/management/m1/ten-week-plan.md`](../../../management/m1/ten-week-plan.md)。

## 门禁摘要

- 第 1-2 周：范围候选、职责、需求追踪、测试策略和第一次汇报材料。
- 第 3 周：原型、架构/API/数据库初稿、智能基线和核心测试场景形成闭环。
- 第 4 周：需求与接口基线冻结，统一环境可启动。
- 第 5-6 周：账号、商品、聊天、议价、订单、见面和双方完成确认形成基础闭环，并完成双账号验收。
- 第 7-8 周：智能候选接入、评估、解释、权限和降级；第 8 周停止新增功能。
- 第 9-10 周：集中测试、恢复演练、发布候选、最终材料和提交包。

每周退出必须有提交号、运行环境、命令/场景、实际结果、失败证据和下一阶段接收人；未完成项必须有 Owner、影响和新截止时间。
