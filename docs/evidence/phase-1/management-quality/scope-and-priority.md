# MQ1-02 范围与优先级

详细范围、MVP/Core/Stretch/Out 分类和重新进入规则见 [`docs/management/m1/project-scope.md`](../../../management/m1/project-scope.md)。

## 当前分类

- MVP/P0：账号、商品、市场、关键词搜索、聊天、报价、订单、见面、双方完成确认、评价、核心举报/通知。
- MVP/P1：收藏、取消/争议、最低管理后台、自动检查与统一环境。
- Core/P2：求购、语义搜索、供需匹配、价格区间、信誉说明和基础审计。
- Stretch：风险实验、描述助手、高级推荐和额外通知渠道。
- Out：支付、物流、真实身份系统、跨校交易、硬件、智能见面推荐和自动治理决策。

MVP 必须独立形成“发布/发现 → 聊天/报价 → 订单 → 见面 → 双方完成 → 评价”的闭环；延期时先移除 Stretch，再缩减 Core，不删除权限、隐私、一致性和异常测试。
