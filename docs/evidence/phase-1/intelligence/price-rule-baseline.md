# AI1-07 价格建议规则基线

## 文档信息

- Owner：M8
- 规则版本：`price-rule-v0.1-draft`
- 状态：Phase 1 候选设计，数值参数须在 Phase 2 用批准数据校准
- 输出性质：建议区间，不是自动定价或成交保证

## 目标与边界

规则基线在没有机器学习模型时提供可解释、可降级的价格建议。它不得修改卖家填写的售价，不得声称预测真实成交价，也不得从来源不明的页面抓取价格。

前端需要展示建议下限、建议上限、可选参考标价、影响因素、数据依据、样本范围、版本和免责声明。当输入或数据不足时，用户仍可手动定价。

## 输入契约

| 字段 | 要求 | 失败行为 |
|---|---|---|
| `category` | 必填，使用冻结枚举 | 返回 `INVALID_INPUT` |
| `condition` | 必填：`new/like-new/good/fair` | 返回 `INVALID_INPUT` |
| `original_price` | 可选，人民币且大于 0 | 忽略非法值并记录原因 |
| `purchase_age_months` | 可选，非负整数 | 非法值按未知处理，不猜测 |
| `brand`、`model` | 可选，规范化文本 | 未知不影响基础交易 |
| `accessory_state`、`defect_tags` | 可选，结构化枚举 | 未提供时扩大区间 |
| `reference_samples` | 可选，仅限许可通过的数据 | 不通过许可门禁则全部拒绝 |

## 处理流程

```text
输入校验
  -> 选择参考锚点
  -> 应用成色/年龄/配件调整
  -> 计算区间并做边界检查
  -> 生成逐项解释
  -> 返回版本、依据、限制和降级状态
```

### 1. 参考锚点优先级

1. 同分类、同品牌型号、相近成色、最近 180 天内的有效完成订单中位数。
2. 同分类、相近成色、最近 180 天内的有效完成订单中位数，并扩大区间。
3. 经合理性校验的 `original_price`，使用折旧规则估算，并标记 `ORIGINAL_PRICE_RULE`。
4. 都不可用时返回 `INSUFFICIENT_DATA`，不生成伪精确价格。

完成订单样本少于 5 条时不得展示“市场样本充分”。样本为 5-19 条时使用宽区间；达到 20 条后才允许使用分位数区间，但阈值仍须 M10 在 Phase 2 复核。

### 2. 初始规则参数

以下参数只是可执行基线的候选配置，不是经验结论。Phase 2 必须将其保存在版本化配置中，并使用批准数据校准。

#### 成色保留系数

| 成色 | 中心系数 | 初始范围 | 解释 |
|---|---:|---:|---|
| `new` | 0.95 | 0.88-1.00 | 未使用但仍属于二手交易场景 |
| `like-new` | 0.85 | 0.75-0.93 | 极少使用、无明显瑕疵 |
| `good` | 0.68 | 0.55-0.80 | 轻微使用痕迹、功能正常 |
| `fair` | 0.45 | 0.28-0.62 | 明显使用痕迹；瑕疵需单独说明 |

#### 年龄系数

当有原价但没有有效成交样本时，使用：

```text
age_factor = max(category_floor, annual_retention ^ (purchase_age_months / 12))
```

| 分类 | 年保留率候选值 | 下限 | 说明 |
|---|---:|---:|---|
| 数码电子 | 0.78 | 0.25 | 技术更新快，型号信息很重要 |
| 图书教材 | 0.86 | 0.30 | 版本过期应作为独立负向因素 |
| 生活用品 | 0.85 | 0.25 | 卫生、运输和磨损差异大 |
| 服饰鞋包 | 0.75 | 0.15 | 尺码、卫生和磨损导致不确定性高 |
| 运动户外 | 0.84 | 0.25 | 安全相关损伤必须扩大区间 |
| 其他 | 0.80 | 0.20 | 信息不足，默认宽区间 |

#### 基础计算

无有效成交样本但原价可信时：

```text
center = original_price * condition_center * age_factor
lower  = original_price * condition_lower  * age_factor
upper  = original_price * condition_upper  * age_factor
```

若配件缺失或存在瑕疵，只允许降低中心/下限并扩大区间，不允许用未经验证的“热门品牌”把结果抬高。具体调整值留给 Phase 2 配置和评审。

使用有效成交样本时：

- 中心值取中位数，不取容易受极端值影响的均值。
- 样本充分时以第 25/75 百分位为初始区间。
- 样本较少时至少向两侧扩大 15%，并公开样本数量和时间范围。
- 样本跨越不同型号或版本时不得假装为“同型号参考”。

### 3. 边界与舍入

- 所有计算使用人民币分，输出时再转换为元。
- 下限不得小于 0，上限必须大于等于下限。
- 推荐标价必须落在区间内；否则不返回推荐标价。
- 金额小于 100 元按 1 元舍入，100-999 元按 5 元舍入，1000 元及以上按 10 元舍入。
- 若区间宽度超过中心值的 80%，返回 `LOW_CONFIDENCE` 并提示手动定价。

## 输出契约候选

```json
{
  "status": "AVAILABLE",
  "currency": "CNY",
  "lower_bound": 780,
  "upper_bound": 960,
  "recommended_listing_price": 890,
  "basis": "ORIGINAL_PRICE_RULE",
  "sample_size": 0,
  "time_window": null,
  "factors": [
    {"code": "CONDITION_GOOD", "direction": "down", "message": "轻微使用痕迹扩大了折价"},
    {"code": "AGE_18_MONTHS", "direction": "down", "message": "使用时间降低了参考区间"}
  ],
  "rule_version": "price-rule-v0.1-draft",
  "disclaimer": "价格建议仅供参考，最终售价由卖家决定。"
}
```

示例仅说明 schema，不代表真实商品或验证结果。前端不得硬编码“近期 18 条样本”，除非接口确实返回已审计样本数。

## 降级矩阵

| 场景 | 状态 | 用户可见行为 |
|---|---|---|
| 分类或成色非法 | `INVALID_INPUT` | 指出需要修正的字段 |
| 无样本且无有效原价 | `INSUFFICIENT_DATA` | 不显示区间，允许手动定价 |
| 只有原价规则 | `LOW_CONFIDENCE` | 显示宽区间和“规则估算” |
| 服务超时或异常 | `UNAVAILABLE` | 提示暂不可用，不阻止发布 |
| 有少量有效样本 | `LOW_CONFIDENCE` | 显示样本数、时间范围和限制 |
| 数据充分且规则通过 | `AVAILABLE` | 展示区间、解释和免责声明 |

## 最小测试集

1. 全新、原价有效、使用时间为 0。
2. 明显磨损且使用时间很长，验证下限不为负。
3. 原价缺失且无参考样本，必须返回 `INSUFFICIENT_DATA`。
4. 原价为 0、负数、非数字或异常大值，必须拒绝或降级。
5. 样本包含极端值，验证中位数比均值稳定。
6. 配件未知、使用时间未知，区间应扩大而不是猜测。
7. 服务异常时商品发布仍可继续。
