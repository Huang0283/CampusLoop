# AI1-08 价格建议评估方案

## 文档信息

- Owner：M8
- 状态：Phase 1 评估设计，尚无真实指标结果
- 复核人：M10
- 原则：挂牌价与成交价分列；基线与候选使用同一评估集

## 评估问题

1. 规则基线能否对合法输入稳定输出有效区间？
2. 当存在真实完成订单标签时，点估计误差和区间覆盖是否可接受？
3. 结果在分类、成色、价格段和时间段上是否存在明显偏差？
4. 数据或服务不可用时，是否正确降级且不阻塞商品发布？

Phase 1 不填写任何尚未运行的准确率、MAE、MAPE 或覆盖率数字。

## 标签分层

| 标签层级 | 定义 | 允许计算的指标 |
|---|---|---|
| L0 合成样本 | 团队人为生成，只验证逻辑和边界 | 规则通过率、确定性、错误处理；不计算对外效果 |
| L1 挂牌价 | 卖家的公开售价 | 描述性偏差，可辅助产品分析；不得称为成交误差 |
| L2 接受报价 | 买卖双方曾接受但订单未必完成 | 单独实验，不与成交标签混合 |
| L3 完成交易价 | 双方完成确认、无未决争议的最终价格 | MAE、MAPE、区间覆盖率等正式指标 |

报告必须在标题和数据清单中注明标签层级。若没有 L3 数据，只报告规则覆盖与合理性检查，并将预测效果结论标记为 `not evaluated`。

## 数据划分

- 使用时间切分，避免未来交易信息泄漏到过去样本的估价中。
- 同一商品、重复发布、同一订单链和近重复记录只能出现在一个集合。
- 测试集一旦冻结，不用于参数选择或规则调优。
- 固定并记录数据版本、哈希、清洗提交、划分脚本和随机种子。
- 分类、成色和价格段至少保留计数；样本不足的切片不报告不稳定指标。

候选模型与规则基线必须共享相同的测试集、过滤条件、币种、标签口径和指标实现。

## 指标定义

设真实完成交易价为 `y_i`，点建议为 `p_i`，建议区间为 `[l_i, u_i]`，有效样本数为 `n`。

### MAE

```text
MAE = (1 / n) * sum(abs(p_i - y_i))
```

- 单位为人民币元，越低越好。
- 同时报告整体值和主要分类/价格段切片。
- 对业务易解释，但不能反映相对误差。

### MAPE

```text
MAPE = (100% / n) * sum(abs(p_i - y_i) / abs(y_i))
```

- 仅对 `y_i > 0` 的样本计算。
- 低价商品会放大百分比误差，因此必须同时报告 MAE，并按价格段切片。
- 不得通过删除低价样本美化结果；若设最低价格阈值，必须事先冻结并单独报告被排除数量。
- 可补充 sMAPE 作为敏感性分析，但不能临时替换预先登记的主指标。

### 区间覆盖率

```text
Coverage = (1 / n) * sum(1[l_i <= y_i <= u_i])
```

- 越高不一定越好，过宽区间可以虚假提高覆盖率。
- 必须同时报告平均区间宽度和归一化区间宽度。

```text
NormalizedWidth = (1 / n) * sum((u_i - l_i) / y_i)
```

### 规则有效性指标

- 合法输出率：合法输入中返回有效区间或明确降级状态的比例。
- 非法输入拒绝率：坏 schema、非法金额和未知枚举被明确拒绝的比例。
- 确定性：相同输入、数据版本和规则版本是否得到相同结果。
- 解释完整率：有效结果是否包含数据依据、因素、版本和免责声明。
- 降级通过率：样本不足、超时、异常时是否允许用户继续手动定价。

## 切片与失败分析

每次评估至少按以下维度检查：

- 分类：数码、图书、生活、服饰、运动、其他。
- 成色：全新、几乎全新、轻微使用痕迹、明显使用痕迹。
- 价格段：`(0, 50]`、`(50, 200]`、`(200, 1000]`、`1000+`；边界可在数据冻结前调整一次。
- 数据依据：真实样本、中位数回退、原价规则、不可用。
- 时间：按月或阶段检查漂移。

失败样例至少归入：字段缺失、原价不可信、样本稀疏、型号混淆、成色主观、版本过期、极端价格、时间漂移或标签争议。

## 泄漏与偏差风险

| 风险 | 控制措施 |
|---|---|
| 将挂牌价当成交价 | 字段和评估层级强制分离 |
| 同一商品重复进入训练和测试 | 按商品/订单链分组去重后切分 |
| 使用测试集选择参数 | 冻结测试集，只在训练/验证集调参 |
| 高价数码商品主导 MAE | 分类和价格段切片，同时报告样本数 |
| 低价商品主导 MAPE | 与 MAE 联合报告，禁止静默过滤 |
| 只保留成交订单造成选择偏差 | 明确适用范围，不外推至全部挂牌商品 |
| 用户自报成色不一致 | 记录定义和缺失，抽样复核，不猜测 |
| 时间变化导致旧样本失效 | 时间切分、时间窗和漂移报告 |
