## 最小数据字段

### 可进入价格数据集的字段

| 字段 | 必需性 | 说明与约束 |
|---|---|---|
| `sample_id` | 必需 | 随机生成的评估 ID，不复用用户或订单 ID |
| `source_type` | 必需 | `internal_listing`、`completed_order`、`synthetic` 或经批准的公开来源 |
| `license_status` | 必需 | `approved`、`restricted`、`unknown`；只有 `approved` 可进入正式评估 |
| `category` | 必需 | 与商品分类枚举对齐：数码电子、图书教材、生活用品、服饰鞋包、运动户外、其他 |
| `brand`、`model` | 可选 | 规范化后保存；缺失不得猜测 |
| `condition` | 必需 | `new`、`like-new`、`good`、`fair` |
| `original_price` | 可选 | 卖家声明值，必须标记为非验证事实；人民币分为存储单位 |
| `listing_price` | 可选 | 挂牌价，不能自动作为成交标签 |
| `accepted_offer_price` | 可选 | 被接受报价，仅在订单完成后才可成为候选成交标签 |
| `transaction_price` | 正式评估必需 | 完成订单的最终价格；定义需 M6 冻结 |
| `purchase_age_months` | 可选 | 非负整数；未知使用空值，不以 0 代替 |
| `accessory_state` | 可选 | 配件齐全、部分缺失、未知 |
| `defect_tags` | 可选 | 结构化瑕疵标签，不保存未经脱敏的自由文本 |
| `listed_at`、`completed_at` | 可选 | 用于时间切分和漂移检查，按月降精度后用于分析 |
| `campus_zone` | 可选 | 仅保留粗粒度校区；不保存精确见面地点 |
| `record_version` | 必需 | 关联清洗规则、schema 和生成脚本版本 |

### 禁止进入训练、评估和解释日志的字段

- 姓名、邮箱、手机号、学号、账号令牌和设备标识。
- 私聊原文、举报证据原文、精确见面地点和私人空闲时间。
- 商品图片中的人脸、证件或可识别个人环境；Phase 1 不做图像模型。
- 管理员内部备注和未结案举报结论。

## 标签口径

价格字段必须分列保存，不得互相替代：

- `original_price`：卖家声明的新品原价，可能记忆错误或营销夸大。
- `listing_price`：卖家公开标价，反映期望而非成交事实。
- `accepted_offer_price`：报价被接受时的价格，订单仍可能取消。
- `transaction_price`：双方完成确认后记录的最终交易价格；若订单转为争议，是否保留为标签须由 M6/M10 复核。

只有满足以下全部条件的记录可进入正式成交价评估：

1. 订单状态为 `COMPLETED`，且双方针对同一订单版本确认完成。
2. 最终价格来源和币种明确，金额大于 0。
3. 没有未解决争议、测试账号、重复订单或管理员标记的数据质量问题。
4. 已去除用户标识，数据使用目的和保留期限有记录。

## 数据质量门禁

| 检查 | 失败处理 |
|---|---|
| 来源或许可为 `unknown` | 拒绝进入正式数据集 |
| `sample_id` 重复 | 整批检查失败，不静默去重 |
| 价格单位或币种未知 | 拒绝记录 |
| 原价、挂牌价、成交价混列 | 拒绝记录并修正 schema |
| 价格小于等于 0 | 标记非法，不进入指标计算 |
| 成色不在枚举内 | 映射需人工确认；不能确认则剔除并计数 |
| 同一订单重复出现 | 仅保留版本规则确定的一条，并记录去重日志 |
| 时间字段晚于抽取时间 | 标记异常并阻断发布 |
| 描述或图片含个人信息 | 删除敏感字段；无法可靠脱敏则剔除整条记录 |

数据清单必须记录：来源、许可、抽取时间、schema 版本、行数、哈希、缺失率、重复率、异常率和清洗脚本提交号。当前真实行数为 0，不能用前端 Mock 数量替代。

## Phase 2 进入条件

- M6 冻结挂牌价、接受报价和最终交易价的业务定义。

- M8 为每个批准来源保存许可证据与版本化清单。

## 决策

- 规则价格区间：`go`，允许仅使用明确的商品输入和显式降级状态。
- 使用内部挂牌价做描述性统计：`conditional`，不得称为成交价预测。
- 使用真实完成订单训练回归模型：`conditional`，等待合法、去标识且数量足够的数据。
- 抓取外部二手平台：`no-go`，除非后续取得明确许可并经 M1/M5 复核。
