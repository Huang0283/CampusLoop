## 实际失败与修复

1. 首次加载新测试：新 protocol 模块尚不存在，ModuleNotFoundError；这是缺实现，**不是旧代码 bug 复现**。
2. 本机 GBK 默认编码使测试夹具读取 UTF-8 文件失败；为测试读取显式指定 UTF-8。
3. 新增“不得接受未来的人工作证时间”测试，实际出现 AssertionError（预期拒绝但返回 ready）。
   补上人工作证时间检查后，该场景通过；原始 RED 日志保留。
4. 盲审合并测试最初假设输出行序与原夹具一致；实际按 ID 排序。改为按 requestId/productId 核对真实记录，标签和裁决未改变。

原始输出与退出码在 evidence/ 中，不能只引用作者文字作正式验收。
本轮没有新增真实成员查询，没有形成新正式封存集，也没有在新成员 test 上跑候选。
`collection-status.json` 是实际检查结果，当前仍 NOT_READY。
