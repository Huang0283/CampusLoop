# AI4-02 向量索引构建、更新与查询

日期：2026-10-08。此页先固定候选行为，实际命令与运行结果在代码交付后补录，不把尚未存在的命令写成已可用功能。

构建输入为已授权业务快照，复用 Phase 2 schema；输出为 M7 自有的实验 SQLite 索引。按数值商品 ID 固定顺序编码，记录数据范围及事实哈希、模型/预处理/向量维度/schema 版本，全部构建成功才标记 READY。逻辑索引内容可重建比较；SQLite 物理文件字节不作为跨数据库运行的确定性声明。

增量更新应在事务中检查商品 entityVersion。同商品同版本同事实可幂等重试；同版本事实改变报冲突，旧版本不能覆盖新版本。删除/下架保留版本墓碑，防止旧事件复活商品；重复墓碑可幂等。失败的批量更新不能留下部分成功索引。

查询必须同时检查模型、维度、预处理、schema 和当前事实版本；不兼容索引、未知/缺失记录或事实落后不能静默服务新请求。精确余弦只在已通过授权与硬条件的 ID 集合内检索，不能先用全库 topK 再过滤造成合格候选被截掉。

重建、增量更新、查询、未就绪、版本错配、持久化重开及故障行为均通过公共入口的输入/输出验证，测试不会只复刻 SQL 实现细节。真实 M6 事件与生产向量数据库尚未接入，不作为本任务已联调的证据。

当前行为代码尚待测试技能替代流程确认后生成；来源/配置准备不代表索引实现完成。后续实际结果以 [verification.md](verification.md) 为准。
