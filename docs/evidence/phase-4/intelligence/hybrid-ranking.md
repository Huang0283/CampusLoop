# AI4-03 混合搜索与供需语义匹配

日期：2026-10-08。此页固定实现和验收边界；当前行为代码尚待测试技能替代流程确认后生成，不宣称功能已经可调用。

流程：先复用 Phase 3 输入校验、权限、求购有效期及硬约束，得到合格池；分别对合格池生成关键词排序与精确向量排序，再以固定 RRF 参数融合。两个列表从 1 开始计 rank，融合贡献为 weight/(60+rank)；没有进入某列表的商品该列表贡献为 0。不能将原始关键词分与未校准余弦直接相加。

搜索保留 Phase 3 的 public 可见性限制，匹配只允许可信后端代表求购发布者查询；本人商品、已售/删除、预算、类别、成色、必需型号/地点与关键未知条件继续先行拒绝或排除。向量相似也不能放宽这些条件。

结果解释至少包括各列表 rank、余弦、RRF 分项贡献及模型/索引/权重版本，最终 scoreType 明示 RRF，不显示“成交概率”。硬条件贡献仍为空，防止把通过预算当成相关度加分。字段采用内部实验结果，不改公共 OpenAPI 或前端 DTO。

空查询仍走 Phase 3 浏览/仅条件逻辑；显式价格或最新排序保持原定义，不让语义分取代用户指定排序。向量全无结果、索引未就绪/不兼容、模型加载或编码失败时明确回退关键词/规则，附结构化原因；授权拒绝和求购失效不得转降级成功。

本任务只准备私有实验路径，公开服务仍保留 Phase 3 基线。正式模型启用继续 NO_GO；真实效果、延迟和公平对比属于 AI4-04，超时部署和回滚联调属于 AI4-09，不通过本次排序代码伪造完成。
