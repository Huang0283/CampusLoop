# 候选用户与管理员手册

适用源码 `50108a3`，真实 SDK/API，不使用 Mock。日常站点用 `scripts/start-local.ps1`；本轮审计预览 5195 → API 8025 与日常 5174 → 8001 分离。不得混用两套账号或清除日常卷。

## 学生使用

1. 游客访问 `/market` 搜索、分页和商品详情，无需登录。收藏、发布、联系等写入需要登录。界面按钮和后端权限同时约束。
2. `/register` 注册审计用虚构邮箱（可使用 example.invalid）、昵称和密码；这不代表真实校园邮件验证。`/login` 登录；会话以真实 Cookie 管理，刷新后向 API 恢复，不能靠本地硬编码身份。
3. `/publish` 发布商品，填写真实必填字段、价格/成色/地点并上传图片。我的商品中编辑、上下架；只有所有者能维护，不能自购。
4. 买家商品详情联系卖家，在 `/chat` 的真实会话中发消息和报价。卖家接受报价创建唯一订单；重复请求/越权/已占用商品不能重复成交。
5. 订单页面约定未来见面时间和地点，双方确认当前版本；修改后旧确认失效。双方分别确认交易完成，之后各自评价一次。单方确认不等于完成。
6. `/notifications` 查看通知与已读状态；`/report` 按所选对象/原因举报，提交后查看本人记录。卖家/买家可选原因应以实际页面和订单上下文为准。
7. 价格建议只是规则参考；不可用时手动定价。匹配/信誉/风险说明不是成交概率、定价保证、欺诈认定或自动封禁。

## 管理员使用

普通注册不会成为管理员。部署负责人只在独立审计环境执行 `docker exec campusloop-mq5-audit-api-1 python scripts/seed.py --check` 初始化并验证幂等。仓库公开的虚构种子管理员为 `admin.demo@example.com`，演示密码 `Demo@12345`；这些是 seed.py 已公开的演示值，不是实际用户凭据，不可用于生产。已有同 ID 数据不会被种子覆盖，遇到修改过的口令应由部署负责人处理，不改日常账号。管理员登录后进入 `/admin`；实际路由见 `frontend/src/router/index.tsx`，不是未接入主入口的 App.tsx 样板。

处理举报先查看对象和允许的证据，填写处理原因，再执行管理动作。验证处理结果、通知与审计记录一致；风险线索只供人工参考。普通用户或非参与者即使知道 URL 也不能读取私密证据。不要把私聊/见面地点/邮箱复制进公开报告。

## 故障与验收

先核对浏览器地址、checkout、API 和登录环境，再看 `/health`、`/ready`、Worker `/healthz`。连接失败不等于端口冲突；只在确认进程占用后处理端口。智能服务关闭时关键词/手动定价保底，交易应继续；不要切回 Mock。管理员和数据库备份操作应由部署负责人执行，质量恢复脚本只针对审计库。

完整技术部署及测试命令见 `clean-install-report.md`，已知范围见 `release-board.md`。本手册是候选操作说明，不代表课程演示和最终发布已签收。
