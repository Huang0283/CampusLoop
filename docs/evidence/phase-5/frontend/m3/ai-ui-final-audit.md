# M3 智能结果界面复验（FE5-05）

2026-10-25，M10；版本来源和环境见同目录 market-regression.md、browser-responsive-report.md。

原 P5 分支可复现两项回退：模型价格被标为规则、下一次请求失败仍显示旧区间；匹配结果缺少版本、硬约束与有效期。main 已修复这些问题，本 PR 通过 merge 接回已有修复，没有恢复 Mock。

`frontend/tests/live/m3-phase4.spec.ts` 的 10 项在 Chromium 和 Edge 均通过：

- 搜索 503 自动退回一次关键词查询，保留分类/成色/排序，展示实际模式、原因、版本与检索说明。
- 搜索 500/超时可手动改用关键词；关键词失败不循环回退；403 不提供越权恢复入口。
- 匹配显示原因、硬约束、版本、有效期，并明确分数不是成交概率；停留页面时会自动更新已过期提示。无效日期提示未知并允许刷新，403 不展示结果。
- 价格按返回的 method 区分规则/模型；样本不足、不可用、低置信度和降级状态分别提示；保留免责声明及版本。这里使用合成模型响应测试展示逻辑，**不代表真实模型获准上线**。
- 再次计算失败或修改输入即清除旧区间；空免责声明使用安全提示，不把空区间显示为零元。
- 游客可搜索；价格建议、个人匹配仍要求登录。

测试为受控 API fixtures，验证字段消费和交互，不宣称真实 M7/M8 质量或最终跨组联调完成。最终接口以 M6 冻结的 OpenAPI/SDK 为准，在统一 P5 集成提交复验。
