## 缺陷与修复

| 缺陷 | 复现与观察 | 最终处理 |
| --- | --- | --- |
| 上传入口无法使用键盘进入 | 标题之后 Tab 跳过上传区域 | 使用原生按钮语义，处理 Enter 冒泡重复激活 |
| 账号菜单打开及关闭焦点不完整 | 方向键无法操作菜单，Esc 后未返回入口 | 打开时聚焦菜单，Esc 后恢复入口 |
| 交易确认框取消后焦点丢失 | 键盘激活取消按钮后，入口按钮未聚焦 | 取消后恢复完成交易按钮焦点 |
| 用户管理抽屉 Tab 离开抽屉 | 第 5 次 Tab 时焦点落到 BODY | 在首尾可聚焦元素间处理 Tab 循环 |
| 抽屉 Esc 关闭后焦点丢失 | 入口按钮仍存在，但未执行入口 focus 调用 | 记录入口，监听 open 从开到关的变化，在关闭后恢复焦点 |

取消确认框和循环焦点的修复未产生业务写请求。
抽屉焦点处理应用于用户、举报、商品三个管理抽屉；本轮键盘专项直接覆盖用户管理抽屉，其他两个仍需各自复核。
