# CampusLoop 前端用户手册

更新日期：2026-10-23
对应代码：7d16270

本手册介绍当前页面入口和主要操作，供普通用户及管理员使用。
实际可用操作取决于账号角色、资源归属和交易状态；
最终发布环境地址由项目发布负责人提供。

## 登录与注册

游客可以先浏览校园市场、商品详情和求购广场。
点击登录，填写页面标注的校园邮箱和密码。
从受保护页面进入登录时，登录成功会尝试返回原页面及查询条件。

注册页面当前明确标注为教学演示：
可使用页面说明中的测试邮箱，自行设置至少 8 位密码和昵称。
不会发送验证码，注册成功不代表真实学校身份认证。
已有账号请直接登录；遇到注册限流应等待后重试。

刷新页面时会尝试恢复会话；恢复失败时按页面提示重试。
退出登录位于右上角账号菜单内。

## 导航与个人资料

普通用户可通过首页、求购、聊天和交易入口切换页面。
窄屏下使用底部导航。
右上角账号菜单提供个人中心、我的发布、我的收藏、我的举报和退出登录。

在个人中心查看资料概览，编辑昵称、简介、学校、学院和专业，
点击“保存资料”。

使用键盘时，Tab 或 Shift+Tab 移动焦点。
账号菜单可用 Enter 或空格打开，方向键切换选项，
Esc 关闭并返回入口；Tab 用于离开菜单。

## 查找与收藏商品

在校园市场浏览商品，可使用搜索、分类、成色、排序和分页。
查看搜索结果时留意实际检索模式、降级原因等提示。
智能检索失败且页面提供入口时，可选择“改用关键词搜索”。

商品详情展示图片、价格、成色、卖家、地点和描述。
多图商品可切换查看图片。
登录普通用户账号后可以收藏、取消收藏，或联系卖家。
商品状态及本人身份可能使联系按钮不可用。

我的收藏中可查看及取消收藏。
内容不存在或不可见时，按提示返回列表或首页。

## 发布和管理商品

进入“发布商品”，填写商品名称、图片、分类、成色、售价及校内交易地点。
图片支持 JPG、PNG，单张不超过 5 MiB，商品图片为 1 至 5 张。
上传中或存在阻塞错误时，先处理图片再保存。

原价可留空；填写时不能低于售价。
补充真实使用情况、瑕疵和配件说明后，点击“保存商品”。

图片上传按钮支持 Tab 聚焦，以及 Enter、空格打开文件选择框。

在“我的发布”中管理商品。
根据商品状态使用编辑、上架、下架或删除；
已预订、已售商品的相关按钮可能禁用。
如果商品受到人工治理限制，以服务端返回及页面提示为准。

## 价格建议

在发布页面进入价格建议，填写分类、成色及可选原价，
点击“计算区间”。

查看返回的是模型参考还是规则参考，并留意样本数量、
置信度、降级、影响因素、版本及免责声明。
修改输入后需重新计算，旧结果会清除。
样本不足或服务不可用时，可以结合实际情况手动定价。
价格建议仅供参考，最终价格由买卖双方协商。

## 发布和查看求购

在求购广场搜索和查看需求，点击“发布求购”创建自己的需求。
填写标题、最低与最高预算、最低成色、地点和到期时间。
地点字段中的 ANY 表示不限地点。

本人在求购详情中可进入编辑、关闭求购和规则匹配结果。
其他用户可在允许的状态下联系发布者。

匹配结果包含候选商品、匹配原因、相关度、硬约束、版本和有效期。
相关度不是成交概率。
看到过期、有效期未知或降级提示时，应刷新确认当前结果。

## 聊天与报价

从商品或求购详情联系对方后进入会话。
聊天页可搜索及切换会话、刷新列表、发送文字、插入表情或上传图片。
发送失败时查看提示，再使用“重试发送”。

留意连接状态；打开聊天页面不等同于实时连接已经建立。
需要时加载更早消息。

商品会话可在“报价”区域填写金额并提交。
对方根据当前状态接受、拒绝或还价；
报价发起者可在允许时撤回。
接受报价后生成订单，并将商品锁定为已预订。

## 订单与见面

在交易中心切换“我买到的”“我卖出的”，或使用状态筛选查看订单。
没有订单时显示空状态，可以先完成联系与报价流程。

进入订单详情，查看商品、买卖双方、约定和时间线。
点击“安排见面”或“修改见面约定”，填写地点、日期和起止时间。
页面按北京时间校验未来开始时间。
每次修改会生成新版本，双方都需确认最新约定。

“我已完成交易”位于符合状态的订单详情中，
不是账号菜单里的固定入口。
只有订单进入见面已确认状态时，页面才显示该操作。
应在实际完成交易后确认；买卖双方均确认后订单才完成。

如果取消确认框，可使用取消按钮或 Esc。
符合取消条件时，填写取消原因，再通过“取消订单”操作。
订单完成后，进入“评价交易”填写评分和评价。

## 通知与举报

右上角通知入口显示未读数量。
通知页顶部分类为“全部 / 消息 / 报价 / 匹配 / 系统”，默认“全部”。
分类可使用鼠标点击，也可用左右方向键切换；切换只改变筛选，不会出现文本光标。
点击整条通知可进入相关内容；右侧“标为已读”“查看”是辅助操作，不会误触整行跳转。
通知页和右上角计数共享同一份通知数据，正常情况下每 5 秒刷新。

在相关商品、聊天或订单页面使用举报入口，
选择与对象及事实相符的原因，填写说明，最多附 5 张证据图片。
证据图片按私有用途上传，仅管理员处理时可读取。
卖家自己的商品不显示举报入口，也不能举报自己；
求购详情中的“举报发布者”用于举报发布者本人。
提交后进入“我的举报”查看记录、处理时间、处理说明和状态；
记录较多时可使用上一页/下一页，商品和订单目标可点击回到详情。
管理员处理完成后，举报人会收到“举报已处理”或“举报已驳回”的通知。

## 管理员操作

管理员从管理后台使用用户管理、举报处理和商品治理页签。

用户管理：查看用户列表，打开“详情与人工处理”，
按需主动读取风险线索；禁用或恢复账号时填写原因。
禁用操作涉及会话撤销，应核对对象。

举报处理：查看举报详情，需要证据时主动点击读取入口，
该读取会记录访问审计。
选择处理完成或驳回，填写处理说明后提交。

商品治理：搜索或筛选商品，打开详情，
填写原因后人工下架，或解除人工下架。
解除治理限制后的公开可见性还取决于商品自身状态。

遇到接口尚未接通提示时，当前操作不可完成；
待服务恢复后使用“重新检查接口”。

## 错误处理

- 离线：恢复网络后按提示刷新；提交过的操作先核对结果。
- 超时或服务失败：查看提示，使用页面提供的重试或刷新入口。
- 无权访问：核对账号角色和资源归属。
- 内容不存在或不可见：返回列表确认当前状态。
- 提交失败：先保留输入并核对记录，避免连续重复提交。
