# T3 原始日志目录

存放与服务启动、迁移、故障注入、重启恢复、并发执行相关的原始日志。

## 命名规范

```
<用例ID>-<环境>-<yyyyMMdd-HHmmss>-<sha7>.<扩展名>
```

例：`T3-C10-audit1-20261106-1530-d063588-api.log`

- `用例ID`：`T3-C09` 这样的编号；跨用例的启动日志用 `ENV`。
- `环境`：`audit1`、`audit2`、`vm1` 等本机自定标识，与 `environment.md` 一致。
- `sha7`：执行时的短 SHA，完整 SHA 记在 `execution-log.csv`。

## 内容要求

- 只放原始输出，不做删改；需要说明的写进对应文档，不要改写日志。
- 提交前脱敏：连接串中的口令、Cookie、Token、真人邮箱、本机用户名一律替换为占位符。
- 文件过大时保留错误段与前后各 20 行，注明裁剪位置。
- 不提交空文件或占位日志冒充执行证据。
