# T3 环境、异常、持久化与恢复测试用例（Phase 5）

范围：36 条 = 原 C01–C30 + 本轮新增 T3-C31–T3-C36。

约定：

- 结果只有五种：通过 / 失败 / 阻塞 / 未执行 / 不适用。
- 每条执行记录写入 `execution-log.csv`，必须带实际完整软件 SHA、UI 或 API、数据版本、角色与对象 ID、证据路径、日期。
- 本文件只定义用例与证据要求，**不预填执行结果**；`实际结果` 列在真实执行后由执行人填写。
- 所有写入类操作使用独立审计库与 Redis DB14/15，不在日常库做禁用、下架、复位或故障注入，不通过删除数据卷处理故障。
- 缺子检查不得整条判通过；重复执行写入 `retest-log.csv`，不新增用例编号。
