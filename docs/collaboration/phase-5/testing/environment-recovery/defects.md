## 登记规则

- 一行一个缺陷，ID 形如 `T3-DEF-01`；与 Issue 编号对应时写真实 Issue 编号，不用占位编号。
- `现象` 写可复现的最小步骤与实际观察，不写推测结论。
- `状态` 只能写：新建 / 已修复待复测 / 复测通过 / 复测失败 / 不修复并说明理由。
- 阻塞类问题（环境或权限导致无法执行）登记到 `blocked` 段落，不混入缺陷。
