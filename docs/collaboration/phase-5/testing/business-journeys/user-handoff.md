## 可交接的可复现场景（交 U2/D2 补截图/演示）

以下场景 T2 已在 business/run2 真实验证，U2/D2 需要补过程截图时可按此复现，不另造历史：

1. 游客浏览与筛选：未登录进市场 → 分类/成色筛选 → 搜索 → 翻页 → 打开详情。
2. 买家咨询与报价：B 对商品点"联系卖家"→ 聊天内 `$` 图标发起报价 → A 接受。
3. 卖家发布：A 发布商品（1–5 图）→ 编辑 → 自行下架/上架。
4. 双账号完整交易：报价 → 接受 → 安排见面（未来时间+地点）→ 双方确认 → 双方"我已完成交易"→ 双方评价 → 订单详情"查看评价"。
5. 求购与匹配：发布求购 → "规则匹配结果" → 无匹配/价格建议降级。
6. 举报闭环：B 举报（商品/用户/订单/消息）→ R 处理或驳回 → R 改判 → B 在"我的举报"回看 + 通知。
7. 后台治理：R 用户管理（禁用/恢复+申诉）、商品治理（下架/恢复）、订单管理（搜索/筛选/导出 CSV）、仪表盘、操作日志。

注：这些是合成测试数据下的可复现流程，不代表真人任务或全量测试通过；截图索引需写明软件 SHA、环境、角色、页面/对象 ID、语言、视口和日期。
