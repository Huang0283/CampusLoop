## 执行与版本说明

本文件是待执行定义；所有实际结果继续保持待执行。软件 SHA 见 runtime-evidence.json。使用私有 manifest 解析 A/B/D/R/S 和 P/W 别名，不能把别名当数据库 ID。注册/会话/商品基础数据可用，私聊/订单/约定/举报前置由 T2 在 permission 空间通过合法业务流程建立；缺少前置写阻塞。每项实际执行需记录动作、HTTP/页面反馈、刷新持久化与证据；浏览器用例覆盖桌面和移动尺寸。单独 API 运行不能视为页面用例通过。

C21/C22/C23/C26 的精确拒绝状态需按当前路由及对象可见性确认，既有 403/404 不是同时要求两个状态；C35 区分对象存储私桶拒绝与受保护媒体 API 未认证拒绝，尚未执行前不统一记成一个状态。共享 cookie context 的切换与独立 context 身份隔离分别记录。
