# 身份、资料流程与页面权限矩阵

## 演示身份流程

```mermaid
flowchart LR
    A[未登录访问受保护页面] --> B[/login]
    B --> C{选择演示身份}
    C -->|学生| D[写入 Mock 学生身份]
    C -->|管理员| E[写入 Mock 管理员身份]
    D --> F[/market 或原目标页面]
    E --> G[/admin 或原目标页面]
    F --> H[/profile 编辑资料原型]
    G --> H
    H --> I[退出并清除本地演示身份]
```

本阶段仅写入浏览器 `localStorage`，不调用真实认证接口。校园认证状态、令牌失效规则和隐私字段仍需 M5 确认。

## 页面权限矩阵

| 页面 | 未登录 | 学生 | 管理员 |
|---|---|---|---|
| `/login`、`/register` | 允许 | 允许 | 允许 |
| `/market`、商品与求购页面 | 跳转登录 | 允许 | 当前允许，待 M5 确认是否限制 |
| `/profile`、聊天、交易、通知 | 跳转登录 | 允许 | 当前允许，待 M5 确认是否限制 |
| `/admin` | 跳转登录 | 跳转 403 | 允许 |
| `/403`、`/404` | 允许 | 允许 | 允许 |

## 异常处理约定

- 无登录态：保存来源路径并跳转 `/login`；Mock 登录后返回来源路径。
- 角色不匹配：跳转 `/403`，不得仅隐藏入口后继续渲染后台内容。
- 令牌失效：真实接口返回 401 时清除 token 并回到登录页。
- 接口拒绝：真实接口返回 403 时进入无权限页。
- 校园认证：当前没有真实认证数据，只能展示“模拟/待确认”，不得写成学校已核验。
