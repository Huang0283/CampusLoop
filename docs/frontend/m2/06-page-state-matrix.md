# M2-06 逐页面五类状态矩阵（第一阶段）

## 使用规则

- 本文冻结页面状态设计，不代表真实接口已经接入。
- “加载”用于等待接口、文件或会话恢复；纯跳转页写明不适用。
- “空数据”和“筛选无结果”必须区分；失败状态必须提供恢复动作。
- “无权限”不得只隐藏按钮后继续渲染受限数据。

## 身份、资料与管理

### `/login` 登录

- 加载：提交按钮进入加载态并禁止重复提交。
- 空数据：初始空表单属于正常状态。
- 成功：返回来源路径；没有来源时进入市场。
- 失败：区分字段校验、凭据错误、账号禁用和网络失败，并保留账号输入。
- 无权限：已登录用户允许访问，但提供返回当前身份首页的入口。

### `/register` 注册

- 加载：提交期间锁定重复提交。
- 空数据：初始空表单属于正常状态。
- 成功：进入登录或模拟认证步骤。
- 失败：字段错误定位到输入项，网络失败保留已填内容。
- 无权限：无角色限制，但禁止展示仅管理员可写字段。

### `/profile` 个人资料

- 加载：资料卡和表单使用骨架或 Spin。
- 空数据：可选资料为空时显示“未填写”并提供编辑入口。
- 成功：保存后以权威结果刷新资料卡。
- 失败：保存失败保留草稿并允许重试。
- 无权限：未登录跳转登录；非本人不可进入编辑态。

### `/admin` 管理后台

- 加载：用户、商品和举报列表分别显示局部加载态。
- 空数据：每个管理列表显示独立空状态。
- 成功：展示管理数据和允许的人工操作入口。
- 失败：显示错误原因、重试入口和未加载模块。
- 无权限：普通学生进入 `/403`，不渲染后台数据。

## 商品与求购

### `/market` 市场

- 加载：商品列表骨架，筛选栏保持可见。
- 空数据：区分市场无商品和筛选无结果，后者提供重置筛选。
- 成功：显示分页结果并保留搜索、筛选和排序条件。
- 失败：列表显示重试，已有筛选条件不丢失。
- 无权限：未登录跳转登录。

### `/product/:id` 商品详情

- 加载：图片、标题、价格和卖家区域使用骨架。
- 空数据：商品不存在或已删除时显示原因和返回市场入口。
- 成功：展示商品事实、卖家摘要、联系、收藏、举报商品和举报卖家入口。
- 失败：显示重试和返回市场入口。
- 无权限：未登录跳转登录；无权编辑时不显示编辑能力。

### `/publish` 发布商品

- 加载：图片处理中显示单图进度；提交期间防止重复提交。
- 空数据：初始表单属于正常状态。
- 成功：进入价格建议或我的发布，并明确当前仍是 Mock。
- 失败：区分图片格式/数量、字段校验和提交失败，保留草稿。
- 无权限：未登录跳转登录；被限制发布时展示原因。

### `/publish/price-advice` 价格建议

- 加载：展示正在计算建议的状态。
- 空数据：样本不足时不生成虚假价格，允许返回手动定价。
- 成功：展示区间、影响因素、样本限制和免责声明。
- 失败：明确建议不可用，保留继续发布入口。
- 无权限：未登录跳转登录。

### `/my-products` 我的发布

- 加载：列表或表格骨架。
- 空数据：引导发布第一件商品。
- 成功：区分在售、已预约、已售、隐藏和已下架。
- 失败：显示重试，不把失败误报为空数据。
- 无权限：未登录跳转登录；只能管理本人商品。

### `/favorites` 我的收藏

- 加载：收藏列表骨架。
- 空数据：引导返回市场浏览。
- 成功：显示商品最新状态，已售或下架明确标记。
- 失败：显示重试，不静默清空收藏。
- 无权限：未登录跳转登录。

### `/wanted` 求购市场

- 加载：求购列表骨架。
- 空数据：区分无求购和筛选无结果，并提供发布或重置入口。
- 成功：展示预算、成色、地点和有效期。
- 失败：保留筛选条件并允许重试。
- 无权限：未登录跳转登录。

### `/wanted/:id` 求购详情

- 加载：详情和匹配摘要使用骨架。
- 空数据：不存在、过期或删除分别说明，并提供返回入口。
- 成功：展示求购条件、联系入口和匹配依据。
- 失败：详情与匹配结果可分别失败和重试。
- 无权限：未登录跳转登录；非作者不可编辑或关闭。

### `/wanted/publish` 发布求购

- 加载：提交期间锁定重复提交。
- 空数据：初始表单属于正常状态。
- 成功：进入求购详情或匹配结果。
- 失败：预算、有效期和必填项错误就地提示并保留草稿。
- 无权限：未登录跳转登录；受限账号显示原因。

### `/wanted/matches` 匹配结果

- 加载：结果区域显示匹配中。
- 空数据：说明当前无匹配，并提供修改条件入口。
- 成功：展示相关程度、匹配原因和价格区间，不写成成交概率。
- 失败：模型不可用时标记关键词降级；全部不可用时返回求购详情。
- 无权限：未登录跳转登录；只能查看允许访问的求购结果。

## 聊天、交易与治理

### `/chat` 会话列表

- 加载：会话骨架。
- 空数据：引导从商品或求购详情发起联系。
- 成功：展示会话上下文、最后消息、时间和未读数。
- 失败：显示重试，不清除已有本地会话摘要。
- 无权限：未登录跳转登录；不显示非参与者会话。

### `/chat/:id` 聊天详情

- 加载：历史消息加载态，输入区状态明确。
- 空数据：提示发送第一条消息。
- 成功：显示上下文、历史消息、报价、举报用户和举报消息入口。
- 失败：区分历史加载失败、发送失败和断线，允许补拉或重试。
- 无权限：非会话参与者进入 `/403`，不显示私聊内容。

### `/transactions` 订单列表

- 加载：订单列表骨架。
- 空数据：全部、购买、出售、进行中和已结束分别显示空状态。
- 成功：展示订单状态和下一步操作；购买/出售按当前身份筛选，进行中/已结束按订单状态筛选。
- 失败：显示重试，不把请求失败当作零订单。
- 无权限：未登录跳转登录；仅展示参与的订单。

### `/transactions/:id` 订单详情

- 加载：商品、双方和时间线骨架。
- 空数据：订单不存在时提供返回列表入口。
- 成功：展示状态、事件、约定、双方确认、评价资格和举报交易入口。
- 失败：操作失败不提前推进状态，显示可恢复提示。
- 无权限：非参与者只看允许公开的信息，私密事实和操作全部隐藏。

### `/transactions/:id/meetup` 见面约定

- 加载：约定详情和确认状态加载态。
- 空数据：尚未填写时展示创建约定表单。
- 成功：显示版本、地点、时间和双方确认进度。
- 失败：保存或确认失败时保留输入并允许重试。
- 无权限：非订单参与者进入 `/403`。

### `/transactions/:id/review` 评价

- 加载：订单资格与已有评价检查状态。
- 空数据：尚未评价时展示表单。
- 成功：提交后显示已评价并防止重复提交。
- 失败：保留评分和文字并允许重试。
- 无权限：未完成、已取消、非参与者或重复评价时禁止正常提交。

### `/notifications` 通知

- 加载：通知列表骨架。
- 空数据：全部和各类型分别显示无通知状态。
- 成功：展示未读数、分类、已读状态和有效跳转链接。
- 失败：标记已读失败时恢复原状态并允许重试。
- 无权限：未登录跳转登录，只返回当前用户通知。

## 系统状态页与跳转

### `/403` 无权限

- 加载：不适用。
- 空数据：不适用。
- 成功：说明无权限并提供返回安全页面入口。
- 失败：不适用；页面本身不依赖业务接口。
- 无权限：所有角色可访问，且不泄露受限资源内容。

### `/404` 页面不存在

- 加载：不适用。
- 空数据：不适用。
- 成功：说明路径不存在并提供返回入口。
- 失败：不适用；页面本身不依赖业务接口。
- 无权限：所有角色可访问。

### `/`、`/orders`、`/meeting`、`/profile/transactions` 跳转

- 加载：只显示瞬时路由跳转，不使用业务加载态。
- 空数据：不适用。
- 成功：分别进入 `/market` 或 `/transactions`。
- 失败：目标不存在时统一进入 `/404`。
- 无权限：目标路由继续执行登录与角色守卫。
