# M2-03 导航结构（第一阶段）

## 1. 说明

- 本文件定义未登录用户、学生用户、管理员三种角色的导航结构
- 桌面端使用顶部导航 + 侧边栏
- 移动端使用底部导航
- UI 文案和文档都用中文

## 2. 未登录用户

可见导航：

- 登录
- 注册

不可见：

- 市场
- 个人中心
- 聊天
- 订单
- 管理后台

跳转规则：

- 访问受保护页面时，重定向到 `/login`

## 3. 学生用户

### 顶部导航

- Logo
- 搜索
- 通知
- 个人菜单
  - 个人中心
  - 我的商品
  - 收藏
  - 我的交易
  - 退出登录

### 侧边栏

- 首页
- 市场
- 求购
- 聊天
- 交易

### 移动端底部导航

- 首页
- 市场
- 求购
- 聊天
- 个人中心

## 4. 管理员

### 顶部导航

- Logo
- 通知
- 个人菜单
  - 个人中心
  - 管理后台
  - 退出登录

### 侧边栏

- 管理后台
  - 用户管理
  - 商品管理
  - 举报管理

### 管理员不显示

- 市场
- 求购
- 聊天
- 交易

## 5. 页面与导航对应

| 页面 | 路由 | 导航位置 |
|---|---|---|
| 首页 | / | 侧边栏 首页 |
| 市场 | /market | 侧边栏 市场 |
| 求购市场 | /wanted | 侧边栏 求购 |
| 聊天 | /chat | 侧边栏 聊天 |
| 订单 | /transactions | 侧边栏 交易 |
| 个人中心 | /profile | 顶部 个人菜单 |
| 我的商品 | /my-products | 顶部 个人菜单 |
| 收藏 | /favorites | 顶部 个人菜单 |
| 个人交易中心 | /profile/transactions | 顶部 个人菜单 |
| 通知 | /notifications | 顶部 通知 |
| 管理后台 | /admin | 侧边栏 管理后台 |
