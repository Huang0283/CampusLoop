# M2-03 导航结构（第一阶段）

## 1. 说明

- 本文件定义未登录用户、学生用户、管理员三种角色的导航结构
- 桌面端使用顶部导航 + 侧边栏
- 移动端使用底部导航
- UI 文案和文档都用中文

## 2. 未登录用户

可见导航：

- 登录
- 注册

不可见：

- 个人中心
- 聊天
- 订单
- 管理后台

跳转规则：

- 访问受保护页面时，重定向到 `/login`

## 3. 学生用户

### 顶部导航

- Logo
- 搜索
- 通知
- 个人菜单
  - 个人中心
  - 我的订单
  - 我的发布
  - 我的收藏
  - 退出登录

### 侧边栏

- 首页（`/market`）
- 求购
- 聊天
- 交易

> 「市场」项已移除：它与「首页」同指 `/market`，属重复入口。市场域（首页、商品详情、发布商品、我的发布、我的收藏）的跳转与高亮现统一由「首页」承担。

### 移动端底部导航

- 首页（`/market`）
- 求购
- 聊天
- 个人中心

### 响应式布局规则

- `>= 1200 px`：显示 220 px 固定侧边栏和完整顶部栏，内容区使用最大宽度约束。
- `768-1199 px`：侧边栏收起为图标导航或抽屉入口；顶部搜索缩短，但通知和个人菜单始终可达。
- `< 768 px`：隐藏固定侧边栏，使用底部主导航；页面内容改为单列，表格切换为列表或横向滚动容器。
- 聊天详情在移动端先显示消息区，通过抽屉查看商品/求购上下文；输入区固定在安全区域上方。
- 商品详情、订单详情和见面约定的双栏区域改为单列，主操作保持在首屏或底部操作区。
- 弹窗宽度使用视口约束；举报、评价和确认弹窗在窄屏改为全宽抽屉或接近全宽的 Modal。
- 触控操作目标至少 44 px，长标题允许换行，不依赖悬停展示必要信息。

## 5. 页面与导航对应

| 页面 | 路由 | 导航位置 |
|---|---|---|
| 首页 | / | 侧边栏 首页 |
| 市场 | /market | 侧边栏 首页（「市场」项已并入首页） |
| 求购市场 | /wanted | 侧边栏 求购 |
| 聊天 | /chat | 侧边栏 聊天 |
| 订单与个人交易中心 | /transactions | 侧边栏 交易；顶部「我的订单」也进入此处 |
| 个人中心 | /profile | 顶部 个人菜单 |
| 我的发布 | /my-products | 顶部 个人菜单 |
| 我的收藏 | /favorites | 顶部 个人菜单 |
| 通知 | /notifications | 顶部 通知 |
| 管理后台 | /admin | 侧边栏 管理后台 |
