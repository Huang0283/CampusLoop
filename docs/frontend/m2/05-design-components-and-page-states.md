# M2-05 设计、公共组件与页面状态规范（第一阶段）

## 基础规范

- 页面语言统一使用中文；产品名称统一为 `CampusLoop`，市场模块可显示 `Campus Market`。
- 主操作使用 Ant Design 主色按钮，危险操作使用 `danger`；不通过颜色单独传递状态。
- 页面内容区间距以 8 px 为基础单位；常用间距为 8、16、24、32 px。
- 内容卡片圆角不超过 8 px；现有 12 px 原型样式列入后续统一项。
- 标题层级：页面标题 24-28 px，区块标题 16-20 px，正文 14-16 px。
- 表单必须包含标签、必填标记、校验信息和提交反馈。
- 桌面端采用顶部导航和侧边栏；移动端布局、断点和底部导航待下一阶段实现。

## 公共组件候选

| 组件 | 责任 | 当前状态 |
|---|---|---|
| `PageContainer` | 页面标题、扩展操作和内容边距 | 已有 |
| `Loading` | 页面或区块加载反馈 | 已有 |
| `EmptyState` | 空列表/空搜索结果 | 已有 |
| `ErrorState` | 请求失败及重试入口 | 已有 |
| `NoPermission` | 403 页面 | 已有 |
| `Can` | 交易按钮级权限 | 已有 |
| 全局导航壳 | 顶栏、侧栏、移动导航 | 缺失，各页面仍重复实现 |
| 筛选栏 | 搜索、筛选、排序、重置 | 候选提取 |
| 图片上传器 | 格式、数量、进度、失败重试 | 候选提取 |
| 状态标签 | 商品、求购、报价、订单状态 | 候选提取 |
| 确认弹窗 | 删除、下架、取消等危险操作 | 候选提取 |

## 五类页面状态

| 状态 | 统一表现 | 最低要求 |
|---|---|---|
| 加载 | 页面骨架或局部 Spin | 禁止无反馈白屏 |
| 空数据 | `EmptyState` + 可执行下一步 | 区分无数据和筛选无结果 |
| 成功 | 页面结果更新 + 成功反馈 | 不只写控制台日志 |
| 失败 | `ErrorState` 或表单错误 + 重试 | 保留用户输入 |
| 无权限 | `/403` 或禁用操作并说明原因 | 不泄露受限数据 |

当前 M2/M3 页面以成功态静态 Mock 为主；其余四类状态属于验收说明，后续接接口时必须按本表实现，不得把静态 Mock 视为真实联调。
