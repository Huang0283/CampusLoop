# 页面与路由总表（M2，第 1 阶段）

## 1. 说明

- 本表用于统一页面名称、路由、访问角色、优先级、负责人和计划周次
- 本阶段不要求实现正式页面，只做原型和文档
- 每个页面至少覆盖：加载、空数据、成功、失败、无权限

## 2. 角色

- 公开：未登录可访问
- 学生：登录后的普通用户
- 管理员：拥有管理权限的用户
