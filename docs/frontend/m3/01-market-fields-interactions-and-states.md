# M3-01 市场与求购字段、交互和状态（第一阶段）

## 页面字段

| 模块 | 主要字段 | 关键枚举/约束 |
|---|---|---|
| 商品列表 | 标题、价格、成色、学校、状态、分类、图片 | 状态：在售、已预约、已售、隐藏、已下架 |
| 商品发布 | 图片、分类、成色、原价、售价、描述、地点 | 最多 5 张 JPG/PNG；售价必填且非负 |
| 商品详情 | 图片、标题、价格、卖家、成色、地点、描述 | 已售/下架时禁止发起交易 |
| 求购发布 | 标题、最低/最高预算、最低成色、地点、有效期 | 最低预算不得高于最高预算；有效期不得早于当前日期 |
| 求购详情 | 标题、预算、成色、地点、分类、截止时间 | 过期或删除状态不可联系 |
| 匹配结果 | 商品、价格、匹配分、匹配原因、建议区间 | 匹配分表示相关程度，不是成交概率 |
| 价格建议 | 建议区间、推荐标价、影响因素、样本范围 | 仅供参考，卖家保留最终定价权 |

## 搜索、筛选与排序

- 商品市场：关键词、分类、价格、成色、地点；综合、最新、价格升序/降序。
- 求购市场：关键词、分类、预算、最低成色；最新、预算升序/降序。
- 筛选变化后页码回到第 1 页；“重置筛选”恢复默认条件。
- 返回列表时应保留筛选条件；当前静态原型未持久化，下一阶段可放入 URL 查询参数。

## 异常状态

| 场景 | 预期反馈 |
|---|---|
| 图片上传中 | 显示单图进度，提交按钮保持可解释状态 |
| 上传失败 | 标记失败图片并提供重试/移除 |
| 格式或数量超限 | 在选择后立即提示，不上传无效文件 |
| 表单校验失败 | 定位到首个错误，保留所有已填内容 |
| 商品已售出/下架/删除 | 展示状态，禁用联系、收藏或编辑中的无效操作 |
| 无权编辑 | 返回 403 或显示无权限状态，不渲染编辑表单 |
| 列表为空 | 区分无发布内容和筛选无结果，并提供发布/重置入口 |
| 匹配服务不可用 | 降级为关键词结果，明确说明未运行智能匹配 |
| 价格建议不可用 | 允许继续手动定价，明确说明建议暂不可用 |
